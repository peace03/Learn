<a id="pixel"></a>

## Pixel / 픽셀

**뜻:** 디지털 그림에서 색을 담는 작은 칸.

**원리·용도:** 같은 크기 그림에 칸이 많으면 작은 무늬를 더 잘 담지만 파일·메모리가 커질 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="resolution"></a>

## Resolution / 해상도

**뜻:** 그림이나 계산 격자의 가로·세로 칸 수.

**원리·용도:** 2048×2048 이미지는 약 419만 칸이다. 화면 해상도와 [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 해상도는 각각 설정한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="channel"></a>

## Channel / 채널

**뜻:** 자료 안에서 구분해 저장하는 값의 줄기.

**원리·용도:** 이미지의 R·G·B·A는 색·투명도 채널이다. 영상 편집의 채널은 줄 배치라는 다른 뜻이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="rgb"></a>

## RGB

**뜻:** 빨강·초록·파랑의 양으로 색을 표현하는 방식.

**원리·용도:** 세 빛을 섞어 화면 색을 만든다. [색 공간](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#color-space)이 다르면 같은 숫자도 다르게 해석될 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="alpha"></a>

## Alpha / 알파

**뜻:** 불투명도나 덮인 비율 등을 나타내는 추가 값.

**원리·용도:** 흔히 0은 투명, 1은 불투명이다. 그림에 값이 있어도 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 설정이 사용하지 않으면 투명해지지 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="uv"></a>

## UV / UV 좌표

**뜻:** 입체 표면의 각 부분이 그림의 어디를 읽을지 정한 2[차원](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#dimension) [좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate).

**원리·용도:** X·Y·Z와 구별하려고 U·V라고 부른다. 재봉틀 옷본처럼 표면을 펼친 자리라고 생각하면 쉽다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="unwrap"></a>

## Unwrap / 언랩

**뜻:** 입체 표면을 [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv) [평면](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#plane)에 펼치는 작업.

**원리·용도:** 곡면을 펴면 늘어남이나 절개가 필요하다. 필요한 경계를 [Seam](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#seam)으로 지정한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="seam"></a>

## Seam / 심 / 절개선

**뜻:** [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv)를 펼칠 때 자를 경계로 지정한 [에지](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#edge).

**원리·용도:** 실제 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)를 찢는 명령은 아니다. 눈에 덜 띄고 왜곡을 줄일 위치에 둔다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="uv-island"></a>

## UV Island / UV 아일랜드

**뜻:** [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv)에서 이어진 한 덩어리.

**원리·용도:** 부츠 몸통과 밑창이 별도 아일랜드일 수 있다. 겹침은 의도한 공유일 수도 오류일 수도 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="texel"></a>

## Texel / 텍셀

**뜻:** [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)를 이루는 한 색·자료 칸.

**원리·용도:** 화면 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel)과 일대일로 대응하지 않는다. 확대하면 한 텍셀이 여러 화면 픽셀을 차지할 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="texel-density"></a>

## Texel Density / 텍셀 밀도

**뜻:** 실제 표면 길이나 면적에 배정한 [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 칸의 밀도.

**원리·용도:** 부위별 밀도가 크게 다르면 한쪽만 흐리게 보인다. 중요한 부위에는 더 많이 배정할 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="uv-stretch"></a>

## UV Stretch / UV 왜곡

**뜻:** 입체 표면과 펼친 그림 사이의 늘어남 차이.

**원리·용도:** 체크 무늬가 길쭉해지면 쉽게 확인한다. 절개·섬 배치·표면 분할을 조절한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="udim"></a>

## UDIM / 유딤

**뜻:** 여러 [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv) 타일에 서로 다른 이미지를 배정하는 규칙.

**원리·용도:** 큰 모델에 많은 [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 공간을 쓰기 좋다. 목적 프로그램과 [셰이더](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader)가 지원하는지 확인한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="texture"></a>

## Texture / 텍스처

**뜻:** 표면 위치에 따라 색이나 [거칠기](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#roughness) 등의 값을 주는 자료.

**원리·용도:** 사진 파일만 뜻하지 않는다. 수학으로 만드는 무늬도 텍스처다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="image-texture"></a>

## Image Texture / 이미지 텍스처

**뜻:** 이미지 파일의 값을 읽는 [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 방식.

**원리·용도:** 어느 [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv)를 읽고 어떤 [색 공간](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#color-space)으로 해석할지 설정한다. 파일 경로가 끊기면 표시가 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="procedural"></a>

## Procedural / 절차적

**뜻:** 규칙과 계산으로 결과를 만드는 방식.

**원리·용도:** [노이즈](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#noise) 무늬는 이미지 없이 생성할 수 있다. 다른 프로그램에 규칙이 없으면 [베이크](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#bake)가 필요할 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="texture-paint"></a>

## Texture Paint / 텍스처 페인트

**뜻:** 표면을 보며 이미지에 색을 칠하는 작업.

**원리·용도:** blend 저장 외에 수정한 이미지의 저장 상태도 확인한다. 연결된 공유 이미지에 칠하면 다른 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)에도 보인다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="uv-editor"></a>

## UV Editor / UV 에디터

**뜻:** [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)한 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)의 [UV 좌표](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv)를 펼쳐 보고 편집하는 창.

**원리·용도:** 이미지 자체의 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel)을 옮기는 것이 아니라 표면이 읽을 주소를 옮긴다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="image-editor"></a>

## Image Editor / 이미지 에디터

**뜻:** 이미지와 렌더 결과 등을 보고 다루는 창.

**원리·용도:** 수정된 이미지의 Image 메뉴에서 저장 상태를 확인한다. blend 저장과 구분한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="texture-coordinate"></a>

## Texture Coordinate / 텍스처 좌표

**뜻:** 무늬를 읽거나 계산할 위치 기준.

**원리·용도:** [UV](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv) 외에도 물체 [좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate) 등을 쓸 수 있다. 같은 무늬라도 기준을 바꾸면 크기·방향이 바뀐다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="mapping"></a>

## Mapping / 매핑

**뜻:** 한 자료의 위치를 다른 자료의 위치에 대응시키는 것.

**원리·용도:** [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 Mapping [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)는 [텍스처 좌표](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture-coordinate)를 이동·[회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)·확대해 무늬 배치를 바꿀 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="material-output"></a>

## Material Output / 재질 출력

**뜻:** 계산한 표면·부피 등의 결과를 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 최종 결과로 전달하는 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node).

**원리·용도:** 중간 [셰이더](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader)를 만들었어도 출력에 연결되지 않으면 원하는 결과가 나타나지 않을 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="bake"></a>

## Bake / 베이크

**뜻:** 복잡한 계산 결과를 다시 쓸 자료로 미리 저장하는 작업.

**원리·용도:** 표면 빛·세부를 이미지로 굳히는 베이크와 물리 움직임을 [프레임](06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#frame)별 저장하는 베이크는 결과 자료가 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="normal-map"></a>

## Normal Map / 노멀 맵

**뜻:** 빛 계산에 쓸 방향 변화를 색 값으로 담은 그림.

**원리·용도:** 작은 홈처럼 보이게 하지만 보통 실제 [윤곽선](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#silhouette)은 바꾸지 않는다. 색 그림이 아니므로 보통 [Non-Color](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#non-color)로 읽는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="bump"></a>

## Bump / 범프

**뜻:** 높이 값의 차이로 빛 계산 방향을 바꾸는 방식.

**원리·용도:** 흑백 높이 그림으로 잔주름을 표현할 수 있다. 실제 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 위치를 옮기는 [Displacement](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#displacement)와 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="displacement"></a>

## Displacement / 디스플레이스먼트

**뜻:** 높이 자료 등으로 실제 표면 위치를 바꾸는 방식.

**원리·용도:** [실루엣](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#silhouette)까지 변할 수 있다. 충분한 표면 분할과 사용하는 렌더 방식의 지원이 필요하다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="material"></a>

## Material / 재질

**뜻:** 표면이 빛을 반사·통과·[방출](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#emission)하는 방식의 설정 묶음.

**원리·용도:** 같은 부츠 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)도 가죽·금속처럼 보이게 바꿀 수 있다. 재질과 [텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 이미지는 다른 [데이터](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## Material Slot / 재질 슬롯

**원리·용도:** 면마다 슬롯을 지정해 밑창과 갑피에 다른 재질을 쓸 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="shader"></a>

## Shader / 셰이더

**뜻:** 표면이나 공간의 빛 반응 등을 계산하는 규칙.

**원리·용도:** [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)은 셰이더와 입력값·[텍스처](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)를 묶어 결과를 만든다. [Blender](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender) [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)가 [Unity](10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#unity)로 그대로 옮겨지는 것은 아니다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="shader-editor"></a>

## Shader Editor / 셰이더 에디터

**뜻:** [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)·월드의 계산 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)를 연결하는 창.

**원리·용도:** 무엇의 재질을 편집 중인지 먼저 확인한다. 공유 재질 변경은 여러 물체에 반영된다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="node"></a>

## Node / 노드

**뜻:** 입력을 받아 한 계산이나 처리를 하는 블록.

**원리·용도:** 이미지 읽기 → [거칠기](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#roughness) 조절 → 표면 계산처럼 연결한다. 연결 없이 놓은 노드는 결과에 쓰이지 않을 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="socket"></a>

## Socket / 소켓

**뜻:** [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)에서 값이 들어오거나 나가는 연결 구멍.

**원리·용도:** 색·숫자·[벡터](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#vector)·형상 등 자료 종류가 있다. 자동 [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)이 되더라도 의미가 맞는지 확인한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="node-link"></a>

## Node Link / 노드 연결

**뜻:** 한 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)의 출력을 다른 노드의 입력에 전달하는 선.

**원리·용도:** 순환 연결이 허용되지 않는 곳이 많다. 오른쪽 결과에서 왼쪽 입력을 거슬러 읽으면 원인을 찾기 쉽다.

## Node Group / 노드 그룹

**뜻:** 여러 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)를 하나의 재사용 단위로 묶은 것.

**원리·용도:** 자주 쓰는 계산을 입력·출력만 드러내어 정리한다. 그룹 수정이 공유 사용자에게 반영될 수 있다.

<a id="principled"></a>

## Principled BSDF / 프린시플드 BSDF

**뜻:** 여러 현실 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 주요 성질을 하나로 조절하는 표면 [셰이더](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader).

**원리·용도:** [Base Color](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#base-color), [Metallic](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#metallic), [Roughness](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#roughness) 등을 조합한다. 숫자 하나가 전체 외형을 혼자 결정하지는 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="bsdf"></a>

## BSDF

**뜻:** 빛이 표면에 들어와 어느 방향으로 반사되거나 통과하는지를 설명하는 규칙.

**원리·용도:** 컴퓨터는 시선·조명·[법선](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#normal)과 이 규칙을 함께 계산해 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel) 색을 정한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="pbr"></a>

## PBR / 물리 기반 렌더링

**뜻:** 빛과 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 물리 성질을 바탕으로 외형을 계산하는 접근.

**원리·용도:** 아무 조명에서나 같은 화면색을 보장하지 않는다. 재질 수치를 일관되게 해석하는 데 도움이 된다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="base-color"></a>

## Base Color / 베이스 컬러 / 알베도

**뜻:** 조명 효과를 넣기 전 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 기본 색 성질.

**원리·용도:** [그림자](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shadow)까지 그려진 사진을 넣으면 실제 조명 그림자와 겹칠 수 있다. 금속에서는 반사색 해석도 중요하다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="roughness"></a>

## Roughness / 거칠기

**뜻:** 미세한 표면 방향이 얼마나 흩어졌는지 나타내는 성질.

**원리·용도:** 값이 작으면 반사가 좁고 선명하게, 크면 넓게 퍼져 보인다. 실제 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)를 울퉁불퉁하게 만드는 값은 아니다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="metallic"></a>

## Metallic / 금속성

**뜻:** [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)을 금속 계열 반응으로 얼마나 해석할지 정한 값.

**원리·용도:** 단일 순수 표면은 대체로 금속 또는 비금속으로 분류하고, 경계·혼합 영역은 중간값을 쓸 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="specular"></a>

## Specular / 정반사

**뜻:** 특정 방향 근처로 모여 보이는 반사 성분.

**원리·용도:** 거울·광택의 밝은 부분과 관련된다. 표면 [거칠기](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#roughness)와 [굴절률](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#ior) 등이 모양과 세기를 좌우한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="diffuse"></a>

## Diffuse / 난반사

**뜻:** 여러 방향으로 퍼져 보이는 반사 성분.

**원리·용도:** 무광 종이 같은 표면의 바탕 색을 이해하는 데 도움이 된다. 거친 금속을 단순한 비금속 난반사와 같게 보면 안 된다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="transmission"></a>

## Transmission / 투과

**뜻:** 빛이 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 반대쪽으로 통과하는 성질.

**원리·용도:** 유리의 [굴절](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#refraction)과 투명 그림의 [알파](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#alpha)는 다른 방식이다. 두께와 뒷면도 결과에 영향을 준다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## IOR / 굴절률

**원리·용도:** 유리 경계에서 [굴절](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#refraction)과 반사의 양을 정하는 데 쓰인다. 높인다고 항상 더 좋은 유리가 되지는 않는다.

**원리·용도:** 비금속 표면은 비스듬히 볼 때 반사가 강해지는 경향이 있다.
