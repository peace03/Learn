# 05. 스케일·법선·UV 확인하기

[거울 반전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)은 공간의 방향을 바꿉니다. [Blender](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender)에서 보기 좋은 것과 다른 프로그램으로 넘겨도 정상인 것은 구별해야 합니다. 이번에는 **복사본만** 정리하고, 결과가 달라지면 되돌립니다.

## 1. 스케일 적용의 뜻

[Scale](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#scale) 0.5는 [메시](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) [좌표](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)를 화면에 배치할 때 절반으로 계산한다는 뜻입니다. **[Apply Scale](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply-scale)**은 현재 겉모양을 유지하면서 이 비율을 메시 쪽에 반영하고 물체 Scale을 1로 만듭니다. 크기를 직접 1로 입력하는 것은 물체 크기 자체를 바꾸므로 다릅니다.

1. `Boots_Opposite`만 [선택](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)합니다. [Object Mode](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode)인지 확인합니다.
2. **[Object](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object) → [Apply](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply) → Scale** 또는 **Ctrl+A → Scale**을 선택합니다.
3. 바로 **[F9](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#adjust-last)**로 Adjust Last Operation을 엽니다. Blender 5.2.1에서 제공되는 **[Corrective Flip Normals](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#corrective-flip)**가 켜져 있는지 확인합니다. 이 옵션은 [음수 스케일](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#negative-scale) 적용 때 방향 보정을 수행합니다. 현재 실행 환경에서는 기본값이 켜짐으로 확인되었습니다.
4. N → [Item](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item)에서 Scale X/Y/Z가 모두 1인지 확인합니다. 위치·[실루엣](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#silhouette)·장식 방향이 직전과 같아야 합니다.
5. 결과가 예상과 다르면 Ctrl+Z합니다. 다른 [모디파이어](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier)나 뼈가 이미 연결된 파일이라면 적용 영향을 별도로 판단합니다.

이번에는 [Location](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#location)이나 [All Transforms](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#all-transforms)를 고르지 않습니다. 물체 [오리진](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#origin)·다른 [변환](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)까지 바꿀 필요가 없기 때문입니다. 현재 부츠는 [Quaternion](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#quaternion) [회전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)이 있으므로 회전 숫자를 임의로 0으로 만들지 않습니다. [공식 Apply 설명](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/apply.html).

## 2. 면의 앞뒤 확인

면에는 앞뒤가 있습니다. [법선](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#normal)은 빛 계산 등에 쓰는 수직 방향입니다. 둘을 연결해서 이해하되, ‘[부드러운 음영](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#smooth-shading)’과 ‘면 뒤집기’가 같은 작업이라고 생각하면 안 됩니다.

1. [뷰포트](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport) 오른쪽 위 **[Viewport Overlays](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#overlay)**의 펼침 화살표를 클릭합니다. 두 원이 겹친 아이콘 부근이며 마우스를 올려 이름을 확인합니다.
2. **[Face Orientation](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#face-orientation)**을 켭니다. [Solid](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#solid) 표시에서 보며 원본과 복사본을 비교합니다.
3. 부츠 겉면이 일관된 앞면 방향인지 여러 [시점](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)에서 봅니다. 기본 테마는 보통 앞면 파랑·뒷면 빨강 계열이지만 색과 투명도 설정에 따라 다릅니다.
4. 부츠의 열린 입구 안쪽에서 뒷면이 보이는 것과, 겉면 전체가 뒤집힌 것을 구분합니다.
5. 확인이 끝나면 Face Orientation을 끕니다.

**이상이 있을 때만** 다음 복구를 검토합니다. 복사본 선택 → Tab으로 [Edit Mode](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#edit-mode) → A로 전체 선택 → Mesh → [Normals](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#normals-menu) → [Recalculate Outside](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#recalculate-normals)(Shift+N) → Object Mode 복귀 → 재검사. 연결이 끊긴 조각·열린 표면·[사용자 정의 법선](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#custom-normal)이 있는 모델에서는 자동 결과가 의도와 다를 수 있습니다. 이상해지면 Ctrl+Z하고 해당 부분을 따로 조사합니다. 정상 표면에 습관적으로 재계산을 반복하지 않습니다.

## 3. 그림과 재질 확인

[UV](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#uv)는 표면의 어느 위치가 그림의 어느 칸을 읽는지 나타냅니다. 물체를 거울 반전하면 기존 UV 숫자를 그대로 두더라도 공간에서 무늬가 반전되어 보일 수 있습니다. **글자·로고·좌우 전용 장식**을 확인합니다.

1. 원본과 새 부츠를 함께 보며 뷰포트 오른쪽 위 네 구 표시 중 **[Material Preview](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#material-preview)**를 클릭합니다. 로딩을 기다립니다.
2. 같은 무늬가 보여야 하는 곳이 보이는지, 글자가 거꾸로 보이는지 확인합니다. 환경광이 달라 밝기가 바뀌는 것은 [텍스처](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture) 유실과 구분합니다.
3. [재질](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)을 바꾸기 전 [Properties](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#properties) → Material에서 원본과 같은 재질을 공유하는지 확인합니다. [Shift+D](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#duplicate)여도 재질·이미지가 공유될 수 있습니다.
4. 한쪽만 다른 색으로 만들 목적이라면 재질 이름 옆 사용자 수 숫자로 재질을 별도 복사해야 합니다. 같은 이미지에 직접 칠할 예정이면 이미지도 별도 파일로 복사·저장해야 합니다.

전체 UV를 무조건 뒤집는 방법은 사용하지 않습니다. 다른 무늬까지 바꾸고 겹친 UV의 의미를 망칠 수 있습니다. 현재 목적에서 글자 문제가 없다면 그림은 유지합니다.
