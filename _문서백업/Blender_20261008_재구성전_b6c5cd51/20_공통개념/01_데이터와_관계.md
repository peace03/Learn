# 01. 물체와 데이터는 같은 것이 아니다

먼저: [화면과 조작](../00_시작/01_화면과_조작.md).

## 한 부츠 안에 여러 종류의 자료가 있다

화면에 부츠 하나가 보여도 컴퓨터는 정보를 나누어 저장합니다. **[Object](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)는 어디에 놓을지, [Mesh](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)는 어떤 모양인지, [Material](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)은 빛에 어떻게 보일지**를 담당합니다. 이미지 파일은 재질이 읽는 무늬 자료가 될 수 있습니다.

```text
부츠 Object ── 위치·회전·크기
     ├── Mesh ── 정점 좌표·연결·UV
     └── Material ── 셰이더 계산 ── Image
```

자료를 따로 두면 같은 모양을 여러 위치에 놓거나 같은 가죽 재질을 여러 물체에 쓸 수 있습니다. 대신 한 자료를 공유 중인지 알아야 합니다. 한쪽 부츠를 검게 바꿨는데 다른 부츠도 검게 되는 것은 재질을 함께 썼기 때문일 수 있습니다.

## 복사에도 범위가 있다

| 방법 | 배치 | 메시 편집 | 재질 수정 |
|---|---|---|---|
| [Shift+D](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#duplicate), 기본 복제 설정 | 서로 별개 | 보통 서로 별개 | 공유할 수 있음 |
| [Alt+D](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#linked-duplicate) | 서로 별개 | 같은 메시를 공유 | 공유할 수 있음 |
| 재질 [Single User](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#single-user) 만들기 | 영향 없음 | 영향 없음 | 재질은 별개, 참조 이미지는 여전히 공유 가능 |

‘원본과 독립’이라는 말은 **어느 [데이터](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)가 독립인지**까지 말해야 정확합니다. [bpy](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#bpy) 같은 코드를 쓸 때도 Object 복사와 Mesh 복사는 별도 판단입니다. 공식 복제 설명은 [Duplicate](https://docs.blender.org/manual/id/5.2/scene_layout/object/editing/duplicate.html)를 참고합니다.

## 묶기와 따라가기

[Collection](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#collection)은 물체를 찾기 쉽게 묶습니다. [Parent](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#parent)는 [변환](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform) 관계를 만듭니다. [Join](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#join)은 여러 물체의 자료를 한 물체로 합칩니다. 세 가지는 서로 대신하지 않습니다.

부모 아래 [자식](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#child)은 부모 변환의 영향을 받습니다. 하지만 부츠를 몸체의 자식으로 두면 **몸체 전체의 변환**을 따르는 것이지, 몸 안의 특정 발 모양을 알아서 [추적](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#tracking)하는 것이 아닙니다. 발을 따르게 하려면 뼈나 다른 명시적인 제어 관계가 필요합니다.

[Modifier](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier)는 원래 모양에 계산을 더합니다. 위에서 아래로 순서대로 계산하기 때문에 ‘[미러](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection) 후 두께 추가’와 ‘두께 추가 후 미러’의 경계가 달라질 수 있습니다. [Apply](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply) 전에는 원래 모양과 설정을 [분리](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#separate)해서 고칠 수 있고, Apply 후에는 계산 결과가 기본 자료가 됩니다.

## 어디에서 확인하나

- [Outliner](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner): 물체·Collection·부모 관계.
- [Properties](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#properties)의 [Object Data](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-data): 메시 자료와 사용자 수.
- Material: 재질과 사용자 수.
- Modifiers: 계산 순서와 대상.
- N → [Item](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item): [선택](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)한 물체의 변환.

확인 질문: **Shift+D로 복제한 뒤 새 부츠의 색을 바꾸면 원본도 바뀔 수 있는가?** 답: 그렇습니다. 메시와 달리 재질이 공유될 수 있습니다. 재질을 나눠도 같은 이미지에 칠하면 양쪽에 반영될 수 있습니다.
