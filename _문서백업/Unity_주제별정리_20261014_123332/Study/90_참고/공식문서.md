## 로컬 패키지 소스로 확인한 세부 내용

캐시 폴더 이름의 해시는 PC마다 달라질 수 있습니다. 설치 여부 판단은 manifest·lock·embedded 패키지를 사용하고, 아래 파일은 **세부 동작을 확인하는 근거**로만 썼습니다.

| 패키지 안 경로 | 확인한 내용 |
|---|---|
| URP `Runtime/UniversalRenderer.cs` | RenderingMode 0=Forward, 2=Forward+ |
| URP `Shaders/LitInput.hlsl` | Occlusion은 G, Smoothness는 설정에 따라 텍스처 Alpha를 읽는 경로 |
| URP `Editor/Decal/CreateDecalProjector.cs` | `GameObject/Rendering/URP Decal Projector` |
| URP `Editor/ShaderGraph/AssetCallbacks/CreateLitShaderGraph.cs` | `Assets/Create/Shader Graph/URP/Lit Shader Graph` |
| URP `Editor/Decal/CreateDecalShaderGraph.cs` | Decal 전용 Shader Graph 생성 메뉴 |

## 신뢰할 수 있는 설명 순서

1. 현재 프로젝트에서 어떤 파일이 연결되어 있는가?
2. 그 파일의 설정·코드는 무엇을 하는가?
3. 공식 문서에서 그 기능의 의미와 조건은 무엇인가?
4. 실제 Editor에서 설정이 보이는가?
5. 실제 Play·빌드에서 의도대로 동작하는가?

이 자료는 1~3을 중심으로 작성했고, 4~5는 독자의 실습 확인 항목으로 남겼습니다. 특정 Unity 버전의 과거 장애를 이 프로젝트의 현재 장애라고 옮겨 적지 않았습니다.

## 2026-10-14: Cloth 장의 공식 자료

아래는 기존 6000.0 링크와 별도로 확인한 **6000.6 자료**입니다. UI 이름과 체크 처리 방식은 **6000.6.0f1 태그의 소스**도 대조했습니다. 각 본문·용어 항목에는 관련 API 링크를 붙였습니다.

| 확인 대상 | 근거 |
|---|---|
| 기본 Cloth의 렌더러·충돌 제한·제약 편집 | [Cloth Manual](https://docs.unity3d.com/6000.6/Documentation/Manual/class-Cloth.html) |
| 속성·API 전체 목록 | [Cloth API](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth.html) |
| 기준 위치와 0의 의미 | [ClothSkinningCoefficient.maxDistance](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/ClothSkinningCoefficient-maxDistance.html) |
| 제약 체크·Paint 버튼·자기 충돌 UI 이름 | [ClothInspector.cs, 6000.6.0f1](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.6.0f1/Modules/ClothEditor/ClothInspector.cs) |
| Cloth 전용 중력·천 사이 충돌 설정 | [Physics 설정](https://docs.unity3d.com/6000.6/Documentation/Manual/class-PhysicsManager.html), [PhysicsManagerInspector.cs, 6000.6.0f1](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.6.0f1/Modules/PhysicsEditor/PhysicsManagerInspector.cs) |

| 자기 충돌 간격의 조건 | [selfCollisionDistance](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-selfCollisionDistance.html) |

Manual의 자기 충돌 단락에는 `Inter-Collision`이라는 이름이 섞여 있어, 새 자료의 자기 충돌 조작은 같은 버전 Inspector의 `Self-Collision Distance / Stiffness`를 기준으로 적었습니다. 공식 자료를 대조한 것과 실제 모델에서 실행한 결과는 구분합니다.
