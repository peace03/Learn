# 에셋과 설정의 근거

이 파일은 **고유 이름을 찾는 색인**입니다. 예를 들어 Chibi Robot은 이 프로젝트 로봇 이름이며 외워야 할 그래픽 이론이 아닙니다. Test·CopyPaste·Outline·OasisFog 같은 미확인 커스텀 항목은 이름이 저장됐다는 사실만 확인했습니다. 대응 구현이 확인되지 않아 일반 기능처럼 뜻과 사용법을 만들어 설명하지 않습니다. 아래 값은 초판 파일 분석 시점의 기록입니다.

분석일: 2026-10-07. 파일에 저장된 값입니다. 현재 Editor의 저장 전 상태나 실제 재생 결과를 뜻하지 않습니다.

## 현재 씬을 읽을 때

작성 도중 원본 씬·Chibi Controller·재질의 저장 변경을 감지해 다시 읽었습니다. 아래는 재확인한 파일 상태이며 학습 자료 작성자가 씬을 수정한 것이 아닙니다.

| 대상 | 재확인한 상태 |
|---|---|
| Main Camera | Post Processing 켬, UVC_Reflections 활성, Target=Reflection Point, 해상도 Full |
| Lab_Studio_Env | 씬의 Volume Profile Override가 Lab_Studio.asset을 참조 |
| Chibi Robot | 씬에 프리팹 인스턴스가 있으며 Walking.controller 연결 Override |
| Streetwear Robot_Walk | 존재하나 비활성 Override. Animator는 Walk Controller, Avatar 없음, Root Motion 끔 |
| Streetwear Robot_Runing | 비활성. 자기 Avatar + Running.controller, Root Motion 켬 |
| 여신상 3개 | 비활성 Override |
| Decal Projector, Sphere, Sphere (1) | 재확인한 씬에 존재 |
| FloatingDust | 활성 오브젝트로 저장 |

01~15장의 실습은 선택할 대상을 이름으로 명시합니다. Walk 실습 때는 복사 씬에서 Walk를 켜고 비교를 방해하는 다른 캐릭터를 끕니다.

## Input Actions의 의미

`InputSystem_Actions`에는 Player의 Move·Look·Attack·Interact·Crouch·Jump·Previous·Next·Sprint와 UI 맵이 있습니다. Binding은 키·장치를 액션 의미에 묶는 설정입니다. Move 액션 정의만으로 캐릭터가 걷지는 않습니다. 값을 읽어 이동시키는 코드나 컴포넌트 연결이 따로 필요합니다.
