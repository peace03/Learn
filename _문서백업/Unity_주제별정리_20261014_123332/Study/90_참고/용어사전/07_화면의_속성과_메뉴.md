# 용어 사전 07. 화면의 · 속성과 · 메뉴

[전체 검색 색인](../용어_사전.md) · [학습 목차](../../README.md)

각 항목은 **뜻 → 작동 원리 또는 예 → 적용 조건** 순서입니다. 동일 개념의 한글·영문·약어는 한 항목에서 함께 찾습니다. 서로 다른 개념은 별도 항목으로 둡니다.

근거: [공식 문서 목록](../공식문서.md). 프로젝트 전용 속성은 소스와 저장된 설정이 기준입니다.
