# 캐릭터 옷에 Cloth 적용하기

[Cloth 목차](README.md) · 먼저: [천 한 장 실습](01_천한장_방법.md)

목표: **허리·어깨에 붙는 곳은 몸을 따라가고, 옷 끝은 조금 늦게 따라오며 흔들리게 합니다.** 아래는 처음 설정하는 옷의 복사본을 위한 절차입니다. 완성된 Cloth의 기존 칠하기 값을 전체 초기화하는 절차로 쓰지 않습니다.

준비물은 **몸을 따라 움직이는 옷 메시**입니다. 치마·망토처럼 옷이 별도 물체로 나뉘어 있으면 시작하기 쉽습니다. 몸과 옷이 한 메시라면 몸의 점도 Cloth 대상이 되므로, 먼저 Blender 등에서 옷을 분리하고 뼈 연결을 확인하는 작업이 필요할 수 있습니다.

## 1. 복사 씬에서 옷 찾기

1. Play를 멈추고 현재 씬을 저장합니다.
2. **File > Save As**로 `Assets/_Study/ClothCharacterStudy.unity`에 복사 씬을 저장합니다. `_Study`가 없으면 Project 창에서 먼저 만듭니다.
3. Hierarchy에서 캐릭터 이름 왼쪽 화살표를 펼쳐 옷을 찾습니다. 치마라면 `Skirt`, 망토라면 `Cape`처럼 이름이 붙어 있을 수 있지만 모델마다 다릅니다.
4. 옷 물체를 클릭 → Inspector에서 **Skinned Mesh Renderer**가 있는지 확인합니다. 캐릭터 맨 위 물체가 아니라 **옷을 실제로 그리는 물체**를 선택합니다.
5. **Mesh** 칸이 `None`이 아닌지 확인합니다. Cloth가 이미 있으면 제목 왼쪽 체크를 잠시 끄고 Play를 실행합니다.
6. 기존 애니메이션으로 몸을 움직여, 옷의 허리·어깨도 몸을 따라가는지 확인합니다. 따라가지 않으면 [리깅·스키닝](../10_리깅_Avatar와_애니메이션.md)부터 해결합니다.
7. Play를 멈춥니다. 기존 Cloth를 껐으면 원래 체크 상태로 돌려놓습니다.

이 실습은 **이미 재생되는 애니메이션이 있는 캐릭터**를 전제로 합니다. 그런 캐릭터가 없으면 앞의 천 한 장 실습을 먼저 합니다. 프리팹 원본에 **Apply**를 누르거나 공유 모델·재질을 수정할 필요는 없습니다.

## 2. 붙잡을 곳과 움직일 곳 나누기

1. 옷에 Cloth가 없으면 **Add Component > Cloth**로 추가합니다.
2. 시작값을 **Use Gravity=켬, Use Tethers=켬, Stretching Stiffness=1, Bending Stiffness=0.1, Damping=0.2**로 둡니다. 외부 힘을 따로 쓰지 않는 첫 시험에서는 **External/Random Acceleration을 모두 0**으로 둡니다.
3. **Edit Constraints** → **Select**를 누릅니다. **Visualization > Max Distance**를 선택합니다.
4. Scene을 정면으로 맞춥니다. 옷을 선택한 상태에서 `F`를 누르고 **2D**를 켜면 정면에서 사각형 선택하기 쉽습니다.
5. **Visualization** 목록의 **Manipulate Backfaces**를 켭니다. 정면 뒤에 가려진 점도 함께 고르기 위한 설정입니다.
6. 옷 전체를 사각형으로 선택 → **Max Distance 체크를 켜고 `0`**을 입력합니다. **Surface Penetration 체크는 끕니다.** 처음에는 전체를 몸에 붙여 둡니다.
7. 빈 곳을 클릭해 선택을 해제합니다. 아래 표를 보고 **움직일 부분만** 사각형으로 고릅니다. 선택이 잘못되면 숫자를 바꾸기 전에 빈 곳을 눌러 다시 고릅니다.
8. 선택한 부분의 **Max Distance 체크를 켠 상태로** 이동 거리를 입력합니다. 가장자리를 조금씩 나눠 다시 선택하면 연결 부위부터 끝까지 값을 단계적으로 키울 수 있습니다.

   | 부분 | 치마 예 | 망토 예 | 성인 크기 모델의 시작 예 |
   |---|---|---|---|
   | 고정부 | 허리띠 | 목·어깨 연결부 | 0 |
   | 고정부 바로 아래 | 허리 아래 | 어깨 아래 | 0.01~0.03 |
   | 중간 | 치마 중간 | 등 중간 | 0.03~0.08 |
   | 끝부분 | 치맛자락 | 망토 끝 | 0.08~0.15 |

숫자는 **키 약 1.7 Unity 단위, 크기 기준이 정리된 모델**의 시험 예입니다. 정답이나 권장 규격이 아닙니다. 1 단위를 1m로 만든 모델이면 0.1은 10cm에 해당합니다. 이미 뼈가 연결된 모델의 Scale을 숫자에 맞추려고 임의로 바꾸지 않습니다. 옷이 작은 모델에서는 더 작은 거리로 시험합니다.

## 3. 앞·뒤 점이 같은 의도로 칠해졌는지 확인하기

1. **2D**를 끄고 `Alt+마우스 왼쪽 드래그`로 옷 뒤쪽을 봅니다.
2. **Select**에서 허리·어깨의 점과 끝부분의 점을 하나씩 누릅니다. 고정부는 `0`, 움직일 곳은 의도한 양수인지 확인합니다.
3. 다시 국소적으로 고를 때는 **Manipulate Backfaces**를 끕니다. 앞쪽만 고치려다 뒤쪽까지 바꾸지 않기 위해서입니다.
4. 범위 경계가 너무 급하면 그 주변 점만 골라 중간값을 줍니다. 잘못 변경했으면 `Ctrl+Z`로 한 번 되돌리고 다시 고릅니다.
5. **Edit Constraints**를 끄고 씬을 저장합니다.

점마다 값이 섞인 선택에서는 숫자 칸이 혼합값으로 보일 수 있습니다. 그때 입력하면 **선택된 모든 점이 같은 값으로 바뀝니다.**

## 4. 몸의 충돌체를 옷에 연결하기

이미 해당 뼈를 따라 움직이는 Capsule Collider가 있다면 5번부터 진행합니다.

1. Hierarchy에서 캐릭터 뼈 계층을 펼쳐 해당 부위를 찾습니다. 치마라면 골반·허벅지, 소매라면 위팔·아래팔입니다. 실제 뼈 이름은 모델마다 다릅니다.
2. 뼈를 우클릭 → **Create Empty** → `ClothCol_Thigh_L`처럼 알아볼 이름을 붙입니다. 부모 뼈의 바로 아래 자식인지 확인합니다.
3. 새 물체의 **Transform** 메뉴에서 **Reset** → **Add Component > Capsule Collider**.
4. **Capsule Collider > Edit Collider**를 누릅니다. Scene에서 초록 윤곽의 손잡이를 드래그하거나 **Center·Radius·Height·Direction** 값을 조절해 해당 신체 부위를 감쌉니다. 필요하면 `W`로 위치, `E`로 회전을 조절합니다. Direction은 자식 물체의 어느 축을 캡슐의 긴 방향으로 쓸지 정합니다. 뼈 이름만 보고 Y축이라고 단정하지 않습니다.
5. **옷 물체**를 다시 선택 → **Cloth > Capsule Colliders**를 펼칩니다.
6. **Size**를 연결할 충돌체 수로 정하거나 `+`로 칸을 추가합니다.
7. Hierarchy의 각 충돌체 물체를 **Element 0, Element 1…**에 하나씩 드래그합니다. `None`이 아닌지 확인합니다.
8. 편집을 끝내고 저장합니다. 이 연결을 위해 Rigidbody를 추가할 필요는 없습니다.

충돌체는 몸을 대략 감싸되 시작 자세의 옷을 바깥으로 밀어낼 만큼 크게 만들지 않습니다. 팔과 다리를 하나의 거대한 캡슐로 감싸면 관절을 굽힐 때 옷의 길이 막힙니다. 필요한 부위별로 나눠 배치하고, 애니메이션 중에도 몸을 따라가는지 확인합니다.

## 5. 정지·걷기·급회전으로 시험하기

1. Play 실행 → Scene 탭에서 옷을 봅니다.
2. **정지 자세**에서 허리·어깨가 떨어지지 않고 천이 심하게 떨지 않는지 확인합니다.
3. **걷기**에서 옷 끝이 움직이는지, 다리가 천을 지나치게 뚫지 않는지 봅니다.
4. 캐릭터가 지원하는 **급회전·앉기·달리기**에서도 확인합니다. 없는 동작을 이번 실습을 위해 새로 만들 필요는 없습니다.
5. Play 정지 → 값 **하나** 변경 → 다시 실행합니다. 증상별 첫 변경은 다음 표를 따릅니다.

   | 증상 | 먼저 할 일 |
   |---|---|
   | 거의 안 흔들림 | 끝부분 Max Distance가 0인지 확인한 뒤 조금 늘리기 |
   | 몸에서 너무 멀리 뜸 | 그 부분의 Max Distance 줄이기 |
   | 몸을 뚫음 | 충돌체 목록·위치·크기·뼈 따라감부터 확인 |
   | 고무처럼 늘어짐 | 고정부·Use Tethers·Stretching Stiffness 확인 |
   | 계속 요동함 | 처음부터 충돌체와 겹쳤는지 확인 후 Damping 조금 늘리기 |

각 변경 뒤 같은 동작으로 비교합니다. 마지막에는 정지 상태에서 값을 저장하고 다시 Play해 확인합니다.
