# 검증 기록

기준일: 2026-10-07. 이 파일은 학습 자료가 어떤 근거로 작성되었는지 남깁니다.

## 이번 보강의 확인 범위

바탕화면으로 옮겨진 기존 26개 Markdown을 읽고 부족한 선수 개념·용어·조작을 보강했습니다. 준비 A~C와 USD 04A를 추가해 학습 본문은 22편입니다. 전문 용어는 10개 분야의 749개 개별 항목과 전체 검색 색인으로 정리했습니다. 한글·영문·약어를 같은 개념으로 찾고, 정의에서 사용하는 다른 용어도 바로 따라갈 수 있습니다.

Walk USDZ를 읽기 전용으로 다시 열어 model.usda와 PNG 3장, 단위·시간 설정, ORM 채널 연결을 재확인했습니다. 전용 변환기의 .usda 확장자 검색도 다시 확인했습니다. USD 일반 규칙과 이 도구의 지원 제한을 나눠 적었습니다.

최종 파일·링크·앵커 검사 수치는 아래 **이번 보강 최종 검사**에 기록합니다. 아래 초판 26개·193개 링크 기록은 최초 위치에서의 과거 검사이며 현재 바탕화면 자료의 검사 수치가 아닙니다.

이번에 Unity 소스·설정·에셋은 수정하지 않았습니다. Editor 화면 클릭, Hub 설치, 애니메이션 Preview, Play, 변환, 베이크, 빌드, 성능 측정은 수행하지 않았습니다. 새 USDA 예제는 읽기용이며 파서 실행 검사를 하지 않았습니다. 문서의 손조작 절차와 예상 결과는 독자가 실행할 실습입니다.

## 초판에서 수행한 분석

- Unity 프로젝트 루트·버전·패키지·입력·렌더 설정 확인.
- 두 씬과 주요 프리팹의 직렬화 정보·GUID 참조·Override 추적.
- Assets C# 25개와 Bridge C# 7개의 역할·호출 경로 색인.
- FBX 메타데이터·Controller Motion·독립 AnimationClip 설정 확인.
- Shader Graph의 노드·속성, 직접 작성한 셰이더, Volume·VFX 설정 확인.
- Walk USDZ를 읽기 전용으로 열어 USDA·텍스처 구성·ORM 채널 연결 확인.
- 관련 Unity 공식 문서와 로컬 URP 구현 대조.

Python 표준 라이브러리로 실제 저장 파일을 읽어 검사했습니다. 웹 페이지의 모든 기능과 Unity 메뉴 실행을 자동 검증하는 검사는 아닙니다.

## 원본 파일과 동시 변경

초판 작성자는 당시 프로젝트의 `Docs` 아래 Markdown만 만들고 수정했습니다. 분석 시작 시점의 Assets·Packages·ProjectSettings 파일 해시와 비교했을 때, 문서 작성 도중 아래 파일의 변경이 관찰되었습니다.

- `Assets/VARCO_URP/04.Scenes/Lab_Varco3D_01.unity`

## 발견한 주의점의 상태

ORM 채널 불일치, 정확한 Editor 폴더 경계 부재, 덮어쓰기 가능한 변환 출력, 스크립트 미연결, 일부 코드의 조건·한계를 기록했습니다. 수정 작업은 하지 않았으며, 문제 해결 절차는 독자의 실습 또는 후속 개발을 위한 안내입니다.
