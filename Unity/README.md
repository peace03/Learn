## Cloth 바로가기

[Cloth 기능별 목차](Study/70_물리/Cloth/README.md)에서 첫 실습, 캐릭터 옷, 고정, 중력·바람, 천의 성질, 몸 충돌, 자기 충돌, 천 사이 충돌, 품질·성능을 각각 찾습니다.

이 폴더는 문서입니다. Unity Hub에서 여는 프로젝트는 `C:/KNDA_NCAI/UnityProject/Learning/261007 NC강사님/Unity6.6_URPVarco`입니다. 프로젝트의 Assets·Packages·ProjectSettings가 필요합니다. 실제 소스 링크는 이 PC의 위치를 사용합니다.

기준 버전은 Unity 6000.6.0f1, URP 17.6.0입니다. 주제별 재구성은 문서 정리이며, Unity 클릭·Play·빌드를 새로 검증한 작업은 아닙니다. [확인 범위와 기록](Study/99_참고/검증기록.md)
