# 용어 사전 05. 효과와 · 움직임과 · UI

[전체 검색 색인](README.md) · [학습 목차](../README.md)

각 항목은 **뜻 → 작동 원리 또는 예 → 적용 조건** 순서입니다. 동일 개념의 한글·영문·약어는 한 항목에서 함께 찾습니다. 서로 다른 개념은 별도 항목으로 둡니다.

근거: [Volume](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/Volumes.html), [Avatar](https://docs.unity3d.com/6000.0/Documentation/Manual/ConfiguringtheAvatar.html), [VFX Context](https://docs.unity3d.com/Packages/com.unity.visualeffectgraph@17.0/manual/Contexts.html)

<a id="postprocessing"></a>

## Post Processing · 후처리

그려진 화면에 색·번짐 등의 처리를 적용하는 단계입니다.

재질 자체의 성질 변경과 다릅니다.

<a id="volume"></a>

## Volume · 볼륨

효과가 어느 범위와 정도로 적용될지 정하는 컴포넌트입니다.

카메라 필터·Profile·Override가 함께 맞아야 합니다.

함께 찾기: [Component](01_PC와_Unity.md#component) · [Override](01_PC와_Unity.md#override) · [Volume Profile](#profile) · [Camera](09_보충_기초와_도구이름.md#camera)

<a id="profile"></a>

## Volume Profile · Profile · 프로필

Volume이 사용할 효과 값들을 담은 에셋입니다.

복사 씬도 같은 Profile을 가리키면 수정이 공유됩니다.

함께 찾기: [Volume](#volume)

<a id="global-volume"></a>

## Global Volume

공간 거리 제한 없이 적용 후보가 되는 Volume입니다.

카메라의 Layer Mask 등 다른 조건은 여전히 적용됩니다.

함께 찾기: [Layer](01_PC와_Unity.md#layer) · [Layer Mask](01_PC와_Unity.md#layer-mask) · [Mask](04_표면과_렌더링.md#mask) · [Volume](#volume) · [Camera](09_보충_기초와_도구이름.md#camera)

<a id="local-volume"></a>

## Local Volume

Collider 범위와 기준 위치의 거리에 따라 영향을 주는 Volume입니다.

Global과 다르게 지역 조건을 사용합니다.

함께 찾기: [Collider](02_수학과_모델.md#collider) · [Volume](#volume)

<a id="volume-weight"></a>

## Volume Weight · Weight

Volume 효과가 기여하는 정도입니다. 다른 문맥에서는 가중치를 뜻합니다.

0이면 영향이 없고 보통 1을 최대 영향 기준으로 씁니다.

함께 찾기: [Volume](#volume)

<a id="priority"></a>

## Priority · 우선순위

여러 Volume 등을 처리할 순서와 우선 관계를 정하는 값입니다.

체크 안 된 효과를 우선순위만으로 활성화하지는 않습니다.

함께 찾기: [Volume](#volume)

<a id="bloom"></a>

## Bloom · 블룸

밝은 부분을 주변으로 번져 보이게 하는 화면 효과입니다.

실제 주변 물체를 비추는 Light는 아닙니다.

함께 찾기: [Light](04_표면과_렌더링.md#light)

<a id="tonemapping"></a>

## Tonemapping · 톤매핑

넓은 밝기 범위를 화면에서 표현할 범위로 옮기는 처리입니다.

노출 뒤 최종 픽셀 값이 단순 배수가 아닐 수 있습니다.

<a id="exposure"></a>

## Exposure · Post Exposure · 노출

빛의 밝기를 배율로 조절하는 값입니다.

일반 stop 기반 +1은 약 2배 배율입니다.

함께 찾기: [stop](#stop)

<a id="stop"></a>

## stop · 노출 스톱

밝기 배율을 2배 단위로 세는 노출 표현입니다.

+1은 2배, -1은 1/2배입니다.

<a id="contrast"></a>

## Contrast · 대비

밝고 어두운 차이를 조절하는 성질입니다.

크면 밝은 부분·검은 부분의 정보가 뭉칠 수 있습니다.

<a id="saturation"></a>

## Saturation · 채도

색이 회색에 비해 얼마나 선명한지 나타내는 정도입니다.

밝기와 다른 성질입니다.

<a id="white-balance"></a>

## White Balance · 화이트 밸런스

조명 색의 영향을 보정해 흰색 등의 균형을 맞추는 처리입니다.

Temperature와 Tint를 따로 조절합니다.

함께 찾기: [Temperature](#temperature) · [Tint](#tint)

<a id="color-temperature"></a>

## Color Temperature · 색온도

빛의 색을 온도 기준으로 설명하는 표현입니다.

물리 광원 설정에는 K 단위를 쓰지만 후처리 Temperature 슬라이더와 단위가 같지 않습니다.

함께 찾기: [Post Processing](#postprocessing) · [Temperature](#temperature)

<a id="kelvin"></a>

## Kelvin · K · 켈빈

절대 온도의 단위이며 광원 색온도 표시에 쓰입니다.

컴퓨터 온도나 실행 속도 조절값이 아닙니다.

함께 찾기: [Color Temperature](#color-temperature)

<a id="temperature"></a>

## Temperature

White Balance에서 따뜻함·차가움의 색 균형을 조절하는 값입니다.

프로젝트 Profile의 -10은 광원의 -10K라는 뜻이 아닙니다.

함께 찾기: [Project](01_PC와_Unity.md#project) · [Volume Profile](#profile) · [White Balance](#white-balance)

<a id="tint"></a>

## Tint · 틴트

색을 물들이는 보정값입니다. White Balance에서는 주로 초록·자홍 균형입니다.

Base Map 옆 Tint와 후처리 Tint는 적용 위치가 다릅니다.

함께 찾기: [Base Map](04_표면과_렌더링.md#basemap) · [Post Processing](#postprocessing) · [White Balance](#white-balance)

<a id="color-adjustments"></a>

## Color Adjustments

노출·대비·채도 등의 화면 색 조절 효과 묶음입니다.

Profile 안에서 필요한 항목의 Override를 켭니다.

함께 찾기: [Override](01_PC와_Unity.md#override) · [Volume Profile](#profile)

<a id="lift"></a>

## Lift

주로 어두운 영역의 색·밝기 균형을 조절하는 색 보정입니다.

Gamma·Gain과 함께 사용하되 영향 범위는 겹칠 수 있습니다.

함께 찾기: [Gamma](#gamma) · [Gain](#gain)

<a id="gamma"></a>

## Gamma

중간 밝기 변화나 비선형 밝기 관계를 다루는 말입니다.

Lift/Gamma/Gain의 Gamma 조절과 프로젝트 색 공간 설정은 구분합니다.

함께 찾기: [Project](01_PC와_Unity.md#project) · [Color Space](04_표면과_렌더링.md#color-space) · [Lift](#lift) · [Gain](#gain)

<a id="gain"></a>

## Gain

주로 밝은 영역 쪽의 배율을 조절하는 색 보정입니다.

너무 올리면 밝은 정보가 뭉칠 수 있습니다.

<a id="vignette"></a>

## Vignette · 비네트

화면 가장자리를 어둡게 하는 효과입니다.

화면 구도에 따라 UI나 물체를 가릴 수 있습니다.

함께 찾기: [UI](#ui)

<a id="motionblur"></a>

## Motion Blur · MotionBlur · 모션 블러

노출 시간 동안의 움직임처럼 보이는 흐림 효과입니다.

움직임을 읽기 어려워질 수 있습니다.

<a id="lut"></a>

## LUT · Look-Up Table

입력값에 대응하는 출력값을 미리 적은 표입니다.

색 보정에서는 입력 색을 다른 색으로 바꿉니다.

<a id="color-lookup"></a>

## Color Lookup

LUT를 이용해 화면 색을 바꾸는 후처리입니다.

규정된 이미지 형태와 임포트 설정이 필요합니다.

함께 찾기: [Import](01_PC와_Unity.md#import) · [Post Processing](#postprocessing) · [LUT](#lut)

<a id="shader-graph"></a>

## Shader Graph

계산 노드와 연결선으로 셰이더를 만드는 도구입니다.

최종 출력까지 연결된 계산이 결과에 관여합니다.

함께 찾기: [Shader](04_표면과_렌더링.md#shader)

<a id="node"></a>

## Node · 노드

입력을 받아 결과를 내는 그래프의 계산 단위입니다.

Multiply는 두 값을 곱합니다.

함께 찾기: [Multiply](#multiply)

<a id="graph-port"></a>

## 노드 포트 · 입출력 포트

노드의 값을 넣거나 꺼내는 연결점입니다.

통신 포트 5326과 다른 문맥입니다.

<a id="blackboard"></a>

## Blackboard

Shader Graph의 외부 입력 속성을 정의하는 목록입니다.

Texture2D 속성을 만든 뒤 작업 영역으로 끌어 씁니다.

함께 찾기: [2D](02_수학과_모델.md#2d) · [Texture2D](04_표면과_렌더링.md#texture2d) · [Shader](04_표면과_렌더링.md#shader) · [Shader Graph](#shader-graph)

<a id="exposed"></a>

## Exposed

그래프 속성을 외부 Inspector에서 설정할 수 있도록 노출하는 옵션입니다.

공개된 텍스처 속성에 Material에서 이미지를 넣습니다.

함께 찾기: [Inspector](01_PC와_Unity.md#inspector) · [Texture](04_표면과_렌더링.md#texture) · [Material](04_표면과_렌더링.md#material)

<a id="fragment"></a>

## Fragment · 프래그먼트

표면의 화면 출력 값을 계산하는 단계·블록의 이름입니다.

Shader Graph의 Base Color·Normal 출력 등을 연결합니다.

함께 찾기: [Normal](02_수학과_모델.md#normal) · [Shader](04_표면과_렌더링.md#shader) · [Base Color](04_표면과_렌더링.md#basecolor) · [Shader Graph](#shader-graph)

<a id="sample-texture"></a>

## Sample Texture 2D

UV 위치의 텍스처 값을 읽는 노드입니다.

필터를 거친 값일 수 있어 단순 픽셀 한 개 복사만 뜻하지 않습니다.

함께 찾기: [UV](02_수학과_모델.md#uv) · [Texture](04_표면과_렌더링.md#texture)

<a id="split"></a>

## Split

벡터·색 성분을 각각 나누는 노드입니다.

ORM의 B만 금속성에 연결할 수 있습니다.

함께 찾기: [Metallic](04_표면과_렌더링.md#metallic) · [ORM](04_표면과_렌더링.md#orm)

<a id="combine"></a>

## Combine

여러 성분을 하나의 벡터·색으로 묶는 노드입니다.

R·G·B·A를 원하는 입력으로 채웁니다.

<a id="multiply"></a>

## Multiply

입력 값들을 곱하는 노드입니다.

색에 흰색 1을 곱하면 그 성분은 그대로입니다.

<a id="add-node"></a>

## Add 노드

입력 값을 더하는 계산 노드입니다.

Unity 메뉴의 Add는 항목 추가라는 일반 조작입니다.

함께 찾기: [Unity](01_PC와_Unity.md#unity)

<a id="one-minus"></a>

## One Minus

1에서 입력값을 빼는 노드입니다.

Roughness 0.2를 Smoothness 0.8로 바꾸는 예입니다.

함께 찾기: [Roughness](04_표면과_렌더링.md#roughness) · [Smoothness](04_표면과_렌더링.md#smoothness)

<a id="fresnel"></a>

## Fresnel · 프레넬

보는 각도에 따라 반사 비율이 달라지는 현상과 그 근사 효과입니다.

그래프의 가장자리 효과만으로 전체 물리 반사가 완성되지는 않습니다.

<a id="procedural"></a>

## Procedural · 절차적 생성

그림을 직접 저장하는 대신 규칙과 계산으로 무늬 등을 만드는 방식입니다.

Voronoi·Checkerboard 노드가 예입니다.

함께 찾기: [Voronoi](#voronoi) · [Checkerboard](#checkerboard)

<a id="voronoi"></a>

## Voronoi · 보로노이

여러 기준점 중 가장 가까운 점에 따라 영역을 나누는 계산입니다.

노드에서 얼룩·세포 같은 무늬를 만들 수 있습니다.

<a id="checkerboard"></a>

## Checkerboard

두 값이 번갈아 나타나는 격자 무늬입니다.

프로젝트 깜박임 그래프에 관련 노드가 있습니다.

함께 찾기: [Project](01_PC와_Unity.md#project)

<a id="gradient"></a>

## Gradient · 그라데이션

기준 위치들 사이에서 색 등을 부드럽게 바꾸는 표현입니다.

색 띠를 따라 중간 색을 계산합니다.

<a id="coat-mask"></a>

## Coat Mask

표면 위 투명 코팅층 효과의 정도를 정하는 값입니다.

공개돼 있어도 그래프에서 어디에 연결되는지 확인합니다.

<a id="decal"></a>

## Decal · 데칼

기존 표면에 추가 무늬를 얹는 표현입니다.

바닥 로고나 벽 흔적에 씁니다.

<a id="decal-projector"></a>

## Decal Projector

범위 안의 표면에 데칼 재질을 투사하는 컴포넌트입니다.

Material·투사 방향·폭·높이·깊이를 확인합니다.

함께 찾기: [Component](01_PC와_Unity.md#component) · [Material](04_표면과_렌더링.md#material)

<a id="vfx"></a>

## VFX · Visual Effects

화면에 보이는 특수 효과를 통칭하는 말입니다.

이 프로젝트에서는 먼지 그래프가 예입니다.

함께 찾기: [Project](01_PC와_Unity.md#project)

<a id="vfx-graph"></a>

## VFX Graph · Visual Effect Graph

주로 많은 입자의 생성·변화·그리기를 노드로 구성하는 Unity 도구입니다.

FloatingDust.vfx를 편집합니다.

함께 찾기: [Unity](01_PC와_Unity.md#unity) · [.vfx](03_USD와_파일형식.md#vfx-file)

<a id="particle"></a>

## Particle · 입자

효과를 구성하는 작은 점·면 등의 개별 요소입니다.

각 입자에 위치·크기·수명 등이 있습니다.

<a id="spawn"></a>

## Spawn

입자를 새로 생성하는 단계입니다.

기존 입자를 즉시 지우는 작업과 다릅니다.

<a id="initialize"></a>

## Initialize

새 입자의 처음 위치·크기·수명 등을 정하는 단계입니다.

생성 후 Update에서 값이 달라질 수 있습니다.

함께 찾기: [Update](06_코드와_통신과_검증.md#update)

<a id="vfx-update"></a>

## VFX Update

살아 있는 입자의 값을 시간에 따라 바꾸는 단계입니다.

C# MonoBehaviour.Update와 이름은 같지만 구성 방식이 다릅니다.

함께 찾기: [C#](06_코드와_통신과_검증.md#csharp) · [MonoBehaviour](06_코드와_통신과_검증.md#monobehaviour) · [Update](06_코드와_통신과_검증.md#update)

<a id="output"></a>

## Output

계산된 입자를 어떤 모양·재질로 그릴지 정하는 단계입니다.

생성 단계와 별도입니다.

<a id="spawn-rate"></a>

## Spawn Rate

시간당 새 입자를 만드는 수입니다.

초당 10개, 평균 수명 2초라면 단순 조건에서 약 20개가 살아 있습니다.

<a id="capacity"></a>

## Capacity

그래프가 수용할 수 있도록 정한 입자 수 한도입니다.

현재 살아 있는 수나 초당 생성 수가 아닙니다.

<a id="lifetime"></a>

## Lifetime · 수명

입자가 살아서 처리되는 시간입니다.

생성을 멈춰도 이미 생긴 입자는 수명 동안 남을 수 있습니다.

<a id="rig"></a>

## Rig · 리그

모델을 움직이기 위한 뼈·제어 관계 등의 구성입니다.

Skeleton만으로 리그의 모든 제어 기능을 설명하지는 않습니다.

함께 찾기: [Skeleton](#skeleton)

<a id="rigging"></a>

## Rigging · 리깅

움직일 수 있도록 뼈·제어 관계·변형 연결을 준비하는 작업입니다.

완료 여부는 실제 메시 변형으로 확인합니다.

<a id="skeleton"></a>

## Skeleton · 스켈레톤 · 뼈대

부모·자식으로 연결된 뼈 구조입니다.

애니메이션 경로의 기준이 됩니다.

함께 찾기: [Animation](#animation)

<a id="bone"></a>

## Bone · 뼈

모델 변형에 사용할 개별 관절·변환 대상입니다.
