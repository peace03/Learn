# 기능별 확인 질문

[종합 실습 목차](README.md)

## 모델·프리팹

**확인 질문:** 프리팹 인스턴스의 위치 변경과 프리팹 원본 변경의 차이는? FBX 파일만 복사하면 색과 움직임 연결이 모두 따라오는가?

**답:** 전자는 씬의 해당 물체에, 후자는 원본을 쓰는 인스턴스들에 영향을 줄 수 있습니다. 별도 재질·텍스처·Controller와 참조를 확인해야 합니다.

## 렌더링·카메라

**확인 질문:** Mobile에서 데칼이 사라지면 무엇을 볼까? FOV를 줄이는 것과 물체를 앞으로 옮기는 것은 같은가?

**답:** 사용 중인 Renderer의 Decal 기능부터 봅니다. 두 동작은 원근 관계와 다른 물체의 구도에 서로 다른 영향을 줍니다.

## 조명·베이크

**확인 질문:** 재질이 밝게 빛나면 반드시 주변을 비추는가? Bake 뒤 물체를 움직이면 구운 그림자가 항상 따라오는가?

**답:** 아닙니다. 주변 조명에는 별도 광원 또는 GI 처리가 필요합니다. 미리 계산한 정적 결과는 변경 뒤 다시 구워야 할 수 있습니다.

## 셰이더·VFX

**확인 질문:** 그래프에 노드가 있으면 무조건 화면에 반영되는가? Spawn Rate를 0으로 하면 모든 입자가 같은 순간에 지워지는가?

**답:** 출력까지 연결되어야 합니다. 새 생성이 멈추는 것과 이미 생성된 입자가 사라지는 것은 다릅니다.

## Editor 도구

**확인 질문:** 선택한 물체에 부모가 있을 때 두 Reset 결과가 같을까? 도구 파일이 있으면 항상 버튼으로 노출되는가?

**답:** 좌표 기준이 달라 다를 수 있습니다. 등록과 호출 경로까지 있어야 실제 도구에 나타납니다.

## 성능·빌드

**확인 질문:** Editor에서 잘 실행되는데 빌드가 실패할 수 있는가? Render Scale을 0.8로 줄이면 전체 실행 시간이 항상 64%가 되는가?

**답:** Editor 전용 코드·플랫폼 차이로 실패할 수 있습니다. 줄어드는 픽셀 수와 전체 작업 시간은 다릅니다.
