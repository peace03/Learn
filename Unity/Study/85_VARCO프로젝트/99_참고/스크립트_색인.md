## 읽는 순서

1. `Lab_TransformRotate`: 한 줄 동작과 시간.
2. `Lab_PostSelection`: 참조·배열·함수 연결.
3. `Lab_FadeFromBlack`: 생명주기·보간.
4. `CreateGrounded`: Editor 생성·공유 재질·Undo.
5. `UVC_Reflections`: 이벤트·행렬·임시 자원.
6. `Varco3DExtractTool`: 입력 검증·분기·파일 생성·검증.
7. Bridge의 Types → Menu → Lifecycle → Server → Importer → 각 형식 Importer.

## 현재 사용 여부를 확인하는 방법

- Lab_Canvas 6개: 조사한 씬·프리팹에서 해당 스크립트 GUID 참조 없음. 12·13장처럼 직접 붙이는 실습으로 사용합니다.
- UVC_Reflections: 주 씬 Main Camera에 활성 컴포넌트로 직렬화되어 있음. 실제 렌더 성공은 Play/화면 검증 필요.
- Editor 오버레이: Scene 오브젝트에 붙이는 대신 Editor 등록 속성으로 노출. 컴파일 상태와 Overlay 표시 여부 확인 필요.
- LightUtils: 현재 다른 Assets C# 호출 없음. 실제 버튼은 개별 Create 파일의 경로를 읽습니다.
