## 먼저 알아둘 현재 상태

- 주 실습 씬은 `Lab_Varco3D_01`. 기본 빌드 씬 목록에는 `SampleScene`만 있습니다.
- 현재 Walk FBX는 **Generic**, Runing FBX는 **Humanoid** 설정입니다. 이름에 Walk/Run이 있다고 설정까지 같지는 않습니다.
- 작성 중 씬 저장 변경을 다시 확인했습니다. Chibi Robot이 추가되고 Walk는 꺼져 있으므로, Walk 실습 때는 복사 씬에서 해당 루트를 켭니다. 최근 파일 상태는 [에셋·설정 근거](99_참고/에셋과설정_근거.md)에 적었습니다.
- `Lab_Canvas`의 스크립트 6개는 조사한 씬·프리팹에 연결되어 있지 않습니다. [UI 연결 실습 문서](../81_UI/버튼과화면전환.md)는 직접 연결하는 연습입니다.
- 변환 도구는 같은 이름의 결과물을 지우고 다시 만들 수 있습니다. [VARCO Bridge와 변환 도구 문서](02_Bridge와변환/방법.md)의 백업 절차를 먼저 읽습니다.
- `05.Editor`는 Unity가 특별 취급하는 정확한 폴더명 `Editor`와 다릅니다. 현재 Editor 전용 코드의 빌드 분리 문제는 [빌드와 배포](../83_빌드/빌드와배포.md)에서 다룹니다.
