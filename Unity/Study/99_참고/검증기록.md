## 2026-10-14: Unity Cloth 추가

이번 범위는 학습 문서입니다. 기존 Unity 자료에 **Cloth 목차, 천 한 장 실습, 캐릭터 옷 실습, 개념·원리, 설정·문제 해결, 전문 용어 사전**을 추가했습니다. 앞의 2026-10-07 검사 수치는 과거 기록입니다.

- 프로젝트 파일에서 Unity `6000.6.0f1`, URP `17.6.0`, 기본 모듈 `com.unity.modules.cloth: 1.0.0`을 확인했습니다. `1.0.0`은 모듈 패키지 버전이지 Unity 버전이나 별도 Cloth 제품 버전이 아닙니다.
- 공식 6000.6 Manual·API와 UnityCsReference의 `6000.6.0f1` Cloth Inspector를 읽었습니다. Select에서 0과 제한 해제의 차이, Paint의 별도 활성화 버튼, 자기 충돌 UI 이름을 대조했습니다.
- Physics Manager 소스와 API에서 Cloth 전용 중력 `Physics.clothGravity` 및 Cloth 탭의 `Gravity Override`를 확인했습니다. Rigidbody의 `Physics.gravity`와 구별했습니다. 현재 `ProjectSettings/DynamicsManager.asset`에는 일반·Cloth 중력 모두 `(0, -9.81, 0)`, Cloth Inter-Collision 사용은 꺼짐으로 저장되어 있습니다.
- 사용 가능한 Unity 연결의 프로젝트 루트는 `C:/Project/SteamAttack/SteamAttack`으로 반환되었습니다. 현재 문서가 다루는 `Unity6.6_URPVarco`와 달라 연결된 씬을 변경하거나 실습에 사용하지 않았습니다.
- 문서에 넣은 수치는 연습용 시작값입니다. 특정 옷에서 검증한 최적값이 아닙니다. 다른 프로젝트의 옷 이름·입자 수·칠하기 값을 이 프로젝트의 측정값으로 옮기지 않았습니다.
- 씬 생성, Cloth 부착, 점 칠하기, 충돌체 배치, Play, 빌드, 성능 측정은 실행하지 않았습니다. 원본 Unity 에셋·스크립트·프로젝트 설정도 변경하지 않았습니다.
