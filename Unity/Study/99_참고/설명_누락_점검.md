## 범위와 남는 확인

용어 범위는 현재 학습 본문·설정·코드 설명에서 사용하는 기술 어휘입니다. 한글·영문·약어를 같은 개념에 연결하고, UI 이름·코드 식별자는 별도 분야에 넣었습니다. 사전에서 다시 쓰는 바탕 개념도 기초 항목으로 설명합니다. 임의의 에셋 이름은 에셋 색인, 소스 파일 이름은 스크립트 색인에서 찾습니다.

모든 가능한 그래픽 기술을 다루는 백과사전은 아닙니다. 이 프로젝트를 이해하고 설명된 실습을 따라갈 때 필요한 개념을 범위로 삼았습니다. 독자가 처음부터 막힘 없이 읽는지에 대한 실제 사용자 시험은 하지 않았습니다. 버전별 UI 배치와 실행 결과는 실습에서 직접 확인해야 합니다.

기존 씬 연결·코드 한계는 첫 분석 시점의 파일 근거를 보존했습니다. 이번에는 Walk USDZ 내부 목록·메타데이터·채널 연결과 ExtractTool의 .usda 검색을 재확인했습니다. 에셋 변환이나 코드 수정은 수행하지 않았습니다.
