# 천에 중력과 바람 주기: 따라 하기

[전체 주제 목차](../../../README.md) · [전체 용어 사전](../../../90_용어사전/README.md)

[Cloth 목차](../README.md) · [이 기능의 방법](방법.md) · [이 기능의 개념과 원리](개념과원리.md)

천의 고정부와 이동 범위를 [먼저 설정](../03_고정과이동범위/방법.md)합니다.

1. Play 정지 → 옷 선택 → **Cloth > Use Gravity**를 켭니다.
2. **Edit > Project Settings > Physics > Cloth > Gravity Override**에서 중력을 확인합니다. 기존 천 실습의 기준은 `(0, -9.81, 0)`입니다. 바꾸면 프로젝트의 다른 Cloth에도 영향을 주므로 원래 값을 기록합니다.
3. Project Settings를 닫고 Cloth의 **External Acceleration**을 조절합니다. 기존 10×10 천 실습은 `(0, 0, 3)`으로 시작합니다.
4. **Random Acceleration**은 먼저 0으로 비교한 뒤 첫 천 실습의 `(1, 0, 1)`을 시험합니다. 실제 옷에는 같은 값을 바로 복사하지 않습니다.
5. 저장 → Play → Scene에서 비스듬히 관찰합니다. 변경할 때는 정지하고 값 하나씩 바꿉니다.

캐릭터 이동에 따른 반응은 **World Velocity Scale / World Acceleration Scale**로 따로 조절합니다. Use Gravity를 켜도 모든 점의 Max Distance가 0이면 자유롭게 처지지 않습니다.
