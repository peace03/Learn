# 천 한 장 매달기: 순서대로 따라 하기

[Cloth 목차](../README.md) · 다음: [캐릭터 옷에 적용하기](../02_캐릭터옷/방법.md)

완성 모습: 천의 윗줄은 제자리에 있고 아래쪽은 흔들립니다. 캡슐을 연결하면 천이 캡슐에 걸립니다. **코드와 외부 모델 없이** Unity 기본 Plane으로 연습합니다.

이름이 낯설면 [Cloth 용어 사전](../90_용어사전.md)을 검색합니다. 아래 숫자는 이 연습용 천의 시작값입니다.

## 1. 실습 씬 만들기

1. 위쪽 **Play ▶**가 켜져 있으면 다시 눌러 멈춥니다. `Ctrl+S`로 현재 작업을 저장합니다.
2. **Project** 창의 `Assets`를 우클릭 → **Create > Folder** → `_Study`로 이름을 짓습니다. 이미 있으면 그대로 씁니다.
3. 위쪽 메뉴 **File > New Scene** → **Empty** → **Create**를 누릅니다.
4. `Ctrl+Shift+S` → 프로젝트의 `Assets/_Study` 폴더를 선택 → `ClothStudy.unity`로 저장합니다.

관찰은 **Scene** 창에서 합니다. 이 실습에는 게임 카메라가 필요하지 않습니다.

## 2. 천 모양과 재질 만들기

1. 위쪽 메뉴 **GameObject > 3D Object > Plane**을 누릅니다.
2. **Hierarchy**의 `Plane`을 선택 → `F2` → `ClothTest`로 바꿉니다.
3. **Inspector > Transform**에 아래 값을 입력합니다. X·Y·Z 칸마다 입력하고 `Enter`를 누릅니다.

   | 항목 | X | Y | Z |
   |---|---:|---:|---:|
   | Position | 0 | 6 | 0 |
   | Rotation | -90 | 0 | 0 |
   | Scale | 1 | 1 | 1 |

4. **Mesh Collider** 제목 오른쪽 `⋮` → **Remove Component**를 누릅니다. 이 평면의 일반 충돌 기능은 이번 실습에 사용하지 않습니다.
5. **Project > Assets > _Study**의 빈 곳 우클릭 → **Create > Material** → `ClothTest_Mat`로 이름을 짓습니다.
6. 재질을 선택 → Inspector의 **Shader** 목록 → **Universal Render Pipeline > Unlit**을 선택합니다.
7. **Surface Options > Render Face**를 **Both**로 바꿉니다. **Surface Inputs > Base Map** 옆 색 사각형을 눌러 하늘색 등 눈에 잘 보이는 색을 고릅니다.
8. Project의 `ClothTest_Mat`를 Hierarchy의 `ClothTest` 위로 드래그해 놓습니다.
9. `ClothTest`를 선택 → Scene 창에 마우스를 놓고 `F` → Scene 위쪽 **2D**를 켭니다. 정면에서 네모난 천이 보여야 합니다.

Unity 기본 Plane은 Scale 1에서 한 변이 10 단위인 격자입니다. 이 연습은 **크기가 10×10인 큰 천**을 사용합니다. 캐릭터 옷에 이 숫자를 그대로 복사하지 않습니다. 양면 표시와 빛 없이 보이는 재질은 [URP Unlit 설정](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/unlit-shader.html)에 해당합니다.

## 3. Cloth 추가하고 전체 이동 범위 정하기

1. `ClothTest` 선택 → Inspector 아래 **Add Component** → `Cloth` 검색 → **Cloth** 클릭.
2. Inspector에 **Skinned Mesh Renderer**와 **Cloth**가 보이는지 확인합니다.
3. Cloth에 아래 값을 입력합니다. 표에 없는 값은 그대로 둡니다.

   | 항목 | 값 |
   |---|---|
   | Use Gravity | 켬 |
   | Use Tethers | 켬 |
   | Stretching Stiffness | 1 |
   | Bending Stiffness | 0.1 |
   | Damping | 0.2 |
   | External Acceleration | X=0, Y=0, Z=3 |
   | Random Acceleration | X=1, Y=0, Z=1 |

4. Cloth 위쪽의 **Edit Constraints** 버튼을 누릅니다. 아이콘으로 보이면 마우스를 올려 **Edit cloth constraints**라는 설명을 찾습니다.
5. Scene에 나타나는 **Cloth Constraints** 도구판에서 **Select**를 누릅니다. **Visualization**을 **Max Distance**로 고릅니다.
6. Scene의 천 바깥 빈 곳을 누른 뒤, **천의 모든 점을 감싸도록 마우스 왼쪽 버튼을 누른 채 사각형을 그립니다.** 선택된 점의 수가 표시되는지 확인합니다.
7. 도구판의 **Max Distance 옆 체크를 켜고** 숫자 칸에 `3` → `Enter`를 누릅니다.
8. **Surface Penetration**은 체크를 끕니다. 이번 연습에서는 사용하지 않습니다.

점이 작으면 도구판의 **Constraint Size**를 늘립니다. 이것은 화면에 보이는 점의 크기만 바꿉니다. 도구판이 안 보이면 Scene 창의 **Overlays** 메뉴에서 **Cloth Constraints**를 켭니다. Cloth 편집 버튼도 활성화되어 있어야 합니다.

## 4. 맨 위 한 줄 고정하기

1. **Select** 상태에서 천 바깥의 빈 곳을 클릭해 점 선택을 해제합니다.
2. 천의 **맨 위 한 줄만** 사각형으로 감쌉니다. 옆이나 아래 줄이 같이 선택되면 빈 곳을 눌러 다시 선택합니다.
3. **Max Distance 체크는 켠 채** 숫자만 `0` → `Enter`로 바꿉니다.
4. 위쪽 점 하나를 눌러 값이 `0`, 아래쪽 점 하나를 눌러 값이 `3`인지 각각 확인합니다.
5. Inspector의 **Edit Constraints**를 다시 눌러 편집을 끝냅니다. `Ctrl+S`로 씬을 저장합니다.

**체크 해제는 고정이 아닙니다. 체크를 켜고 `0`을 넣어야 고정됩니다.** 점 색깔만 보고 판단하지 말고 숫자를 확인합니다.

## 5. 실행해 보기

먼저 **Edit > Project Settings > Physics > Cloth** 탭의 **Gravity Override**가 `(0, -9.81, 0)`인지 확인합니다. 이 장의 중력 예시는 이 값을 기준으로 합니다. 값을 바꾸면 같은 프로젝트의 다른 Cloth에도 영향을 주므로, 실습 때문에 바꿀 때는 기존 값을 적어 둡니다. 창을 닫고 아래를 진행합니다.

1. 위쪽 **Play ▶**를 누른 뒤 **Scene** 탭을 다시 클릭합니다.
2. Scene의 **2D**를 끕니다. `Alt`를 누른 채 마우스 왼쪽 버튼으로 드래그해 천을 비스듬히 봅니다.
3. **윗줄은 붙잡혀 있고 나머지 천이 뒤쪽으로 휘거나 흔들리는지** 확인합니다.
4. Play를 멈춥니다. 변화가 너무 작으면 정지 상태에서 **External Acceleration Z**만 `6`으로 바꾸고 다시 실행해 비교합니다.

Play 중 숫자를 바꿔 시험할 수 있지만, 보통 정지하면 그 변경이 돌아옵니다. 남길 값은 정지한 뒤 다시 입력하고 저장합니다.

## 6. 캡슐에 부딪히게 하기

1. Play를 멈추고 Hierarchy 빈 곳을 클릭합니다.
2. **GameObject > 3D Object > Capsule** → 이름을 `ClothObstacle`로 바꿉니다.
3. Transform의 **Position=(0, 6, 1)**, **Rotation=(0, 0, 0)**, **Scale=(2, 2, 2)**를 입력합니다. `Capsule Collider`는 남깁니다.
4. `ClothTest` 선택 → **Cloth > Capsule Colliders** 왼쪽 화살표를 펼칩니다.
5. **Size**를 `1`로 바꿉니다. 목록이 `+` 버튼으로 보이면 한 칸을 추가합니다.
6. Hierarchy의 **ClothObstacle**을 **Element 0** 칸 위로 드래그해 놓습니다. 칸에 `ClothObstacle (Capsule Collider)`가 들어갔는지 확인합니다.
7. `Ctrl+S` → Play → Scene을 비스듬히 보며 천이 캡슐 표면을 따라 휘는지 확인합니다. 캡슐은 천의 뒤쪽에 있으며 시작 시 표면이 천에 닿는 배치입니다.
8. 비교하려면 Play를 멈추고 **Element 0만 None으로 바꾼 뒤** 다시 실행합니다. 비교가 끝나면 충돌체를 다시 연결하고 저장합니다.

천의 위치와 힘에 따라 접촉 모양은 달라집니다. 캡슐 자체가 어둡게 보이면 `ClothTest_Mat`를 복제해 다른 색으로 바꾸고 캡슐에 넣어도 됩니다. Scene에서 캡슐을 선택하면 초록색 충돌 윤곽으로 위치를 확인할 수 있습니다.

## 완료 확인

- 윗줄의 Max Distance는 `0`, 다른 점은 `3`이다.
- 천이 움직이고, 등록한 캡슐을 만날 때 모양이 달라진다.
- Play를 멈추고 다시 실행해도 같은 설정으로 시작한다.

막히면 [증상별 확인 순서](../99_문제해결.md#troubleshooting)를 봅니다.
