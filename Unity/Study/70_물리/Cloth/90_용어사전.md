<a id="cloth"></a>

## Cloth · 클로스 · UnityEngine.Cloth

메시의 점들을 움직여 천의 처짐과 흔들림을 계산하는 Unity 기본 컴포넌트입니다. Skinned Mesh Renderer와 함께 쓰며, 고정부·이동 범위·충돌 대상을 따로 정합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth.html)

<a id="cloth-dynamics"></a>

## Cloth Dynamics · 클로스 다이내믹스

Unity 기본 Cloth와는 별개인 천 시뮬레이션 제품 이름입니다. 이름에 Cloth가 들어가도 컴포넌트·칠하기 도구·지원 충돌 방식이 같다고 가정하지 않습니다. 이 장에서는 기본 Cloth만 설명합니다.

<a id="simulation"></a>

## Simulation · 시뮬레이션 · 모의 계산

규칙과 현재 상태를 이용해 다음 상태를 계산하는 것입니다. Cloth는 실제 실 한 올을 그대로 복제하기보다 계산 가능한 점과 제약으로 천의 움직임을 근사합니다.

<a id="cloth-particle"></a>

## Cloth Particle · 천 입자

천의 위치와 움직임을 계산하는 점입니다. 불꽃 효과의 입자와는 용도가 다릅니다. 원본 메시의 정점과 번호가 항상 같지는 않습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-vertices.html)

<a id="constraint"></a>

## Constraint · 제약 · 구속 조건

계산 결과가 지켜야 할 조건입니다. 한 점을 기준 위치에 붙이거나, 두 점이 지나치게 벌어지지 않도록 하는 것이 예입니다.

<a id="pin"></a>

## Pin · Fixed · 고정점 · 고정부

Cloth에서 기준 위치를 그대로 따라가게 만든 점 또는 영역입니다. Max Distance 체크를 켜고 0으로 정합니다. 애니메이션으로 기준 위치가 움직이면 고정점도 따라갑니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/ClothSkinningCoefficient-maxDistance.html)

<a id="max-distance"></a>

## Max Distance · 최대 이동 거리

천의 점이 스키닝된 기준 위치에서 벗어날 수 있는 최대 거리입니다. 양수를 주면 그 범위 안에서 움직이고, 0이면 기준 위치에 놓입니다. 물체 전체의 이동 거리 제한이 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/ClothSkinningCoefficient-maxDistance.html)

<a id="unconstrained"></a>

## Unconstrained · 제한 없음

특정 제약을 사용하지 않는 상태입니다. Max Distance 체크를 끄면 그 거리 제한을 쓰지 않습니다. 체크를 켠 0과는 정반대의 의미이며, 다른 제약과 충돌은 별도로 작용할 수 있습니다.

<a id="gravity"></a>

## Gravity · 중력

물체의 속도를 정해진 방향으로 바꾸는 가속도입니다. 지구의 중력을 흉내 낼 때 보통 아래 방향을 씁니다. Unity 6.6의 Cloth와 Rigidbody는 중력 설정을 구별해 확인합니다.

<a id="cloth-gravity"></a>

## Cloth Gravity · Gravity Override · Physics.clothGravity

프로젝트의 Cloth에 적용하는 중력 벡터입니다. Unity 6.6의 Physics 설정 안 Cloth 탭에서 확인하며, 6000.6.0f1 UI 이름은 Gravity Override입니다. 각 Cloth의 Use Gravity가 켜져 있어야 적용됩니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Physics-clothGravity.html)

<a id="rigidbody-gravity"></a>

## Physics.gravity · Rigidbody 중력

Rigidbody가 사용하는 프로젝트 중력 값입니다. Unity 6.6에서 Cloth 중력을 확인하려면 별도의 Physics.clothGravity와 Cloth 탭을 봅니다. 두 값이 우연히 같을 수는 있지만 같은 설정 이름은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Physics-gravity.html)

<a id="use-gravity"></a>

## Use Gravity · 중력 사용

Cloth에 중력을 적용할지 정하는 체크입니다. 켜도 고정된 점은 자유 낙하하지 않습니다. 꺼도 다른 가속도나 캐릭터 이동 때문에 움직일 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-useGravity.html)

<a id="velocity"></a>

## Velocity · 속도

위치가 얼마나 빠르게, 어느 방향으로 바뀌는지를 나타내는 값입니다. 초당 오른쪽으로 1m라면 방향과 크기를 함께 가진 속도입니다.

<a id="acceleration"></a>

## Acceleration · 가속도 · m/s²

속도가 얼마나 빨리 바뀌는지를 나타냅니다. 1m/s²는 1초 동안 속도가 1m/s만큼 바뀌는 가속도입니다. 속도 자체와 구별합니다.

<a id="inertia"></a>

## Inertia · 관성

움직이던 상태를 이어 가려는 성질입니다. 몸이 갑자기 멈췄을 때 옷 끝이 계속 움직이려는 모습을 이해하는 데 필요합니다.

<a id="time-step"></a>

## Time Step · 시간 간격

계산에서 한 번에 진행하는 시간의 길이입니다. 0.02초라면 0.02초 뒤의 상태를 계산합니다. 화면을 그리는 간격이나 Cloth의 반복 횟수와 같은 말은 아닙니다.

<a id="damping"></a>

## Damping · 감쇠

천의 움직임을 잦아들게 하는 성질입니다. Cloth의 값은 0~1이며 0은 이 감쇠를 끕니다. 고정 위치나 천의 이동 한계를 정하는 값은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-damping.html)

<a id="stretching"></a>

## Stretching Stiffness · 늘어남 강성

천이 길게 늘어나는 데 저항하는 정도입니다. Cloth에서는 0보다 크고 1 이하의 값입니다. 강성이 커도 별도의 고정부가 없으면 천 전체가 움직일 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-stretchingStiffness.html)

<a id="bending"></a>

## Bending Stiffness · 굽힘 강성

천이 접히는 데 저항하는 정도입니다. 0~1이며 0은 굽힘 저항 계산을 끕니다. 천을 두껍게 그리는 기능은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-bendingStiffness.html)

<a id="tethers"></a>

## Use Tethers · Tether · 테더

고정된 점을 기준으로 움직이는 점이 너무 멀리 늘어지는 것을 억제하는 보조 제약입니다. 먼저 고정부를 만들어야 그 기준이 생깁니다. 중력이나 Max Distance를 대신하는 스위치는 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-useTethers.html)

<a id="external"></a>

## External Acceleration · 외부 가속도

천에 계속 더하는 일정한 가속도입니다. X·Y·Z 성분으로 방향과 크기를 정합니다. 바람에 밀리는 깃발을 시험할 때 사용할 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-externalAcceleration.html)

<a id="random"></a>

## Random Acceleration · 무작위 가속도

천에 불규칙하게 더하는 외부 가속도입니다. 값이 매번 똑같은 힘만 받는 듯한 움직임을 줄이고 바람의 흔들림을 흉내 낼 때 씁니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-randomAcceleration.html)

<a id="world-velocity"></a>

## World Velocity Scale · 이동 영향 배율

캐릭터가 세계 좌표에서 움직이는 것이 천에 미치는 영향의 비율입니다. 천의 크기를 바꾸는 Transform Scale과는 다릅니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-worldVelocityScale.html)

<a id="world-acceleration"></a>

## World Acceleration Scale · 가속 영향 배율

캐릭터의 세계 좌표 가속이 천에 미치는 영향의 비율입니다. 출발·급정지·방향 전환 때 반응을 비교하며 조절합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-worldAccelerationScale.html)

<a id="mass"></a>

## Mass · 질량

물체의 운동 상태를 바꾸기 어려운 정도와 관련된 물리량입니다. 같은 힘이라면 질량이 큰 물체의 가속도가 작습니다. Cloth Inspector의 Collision Mass Scale은 옷 전체의 kg 값을 직접 지정하는 칸이 아닙니다.

<a id="friction"></a>

## Friction · 마찰

접촉한 표면끼리 미끄러지는 것을 방해하는 성질입니다. Cloth에서는 몸과 접촉할 때의 미끄러짐에 관여하며, 공중에서 흔들림을 줄이는 Damping과 다릅니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-friction.html)

<a id="collision-mass"></a>

## Collision Mass Scale · 충돌 질량 배율

충돌 중인 입자의 질량을 얼마나 늘려 계산할지 정하는 값입니다. 전체 옷을 무겁게 만드는 일반 질량 입력칸으로 해석하지 않습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-collisionMassScale.html)

<a id="capsule-collider"></a>

## Capsule Collider · 캡슐 충돌체

원기둥 양 끝에 반구가 붙은 형태의 충돌 경계입니다. 팔다리를 대략 감싸기 좋고 Cloth의 Capsule Colliders 목록에 연결할 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider.html)

<a id="sphere-collider"></a>

## Sphere Collider · 구 충돌체

공 모양의 충돌 경계입니다. Cloth에서는 Sphere Colliders 항목의 First 또는 Second에 연결합니다. 화면에 구 메시가 없어도 충돌체는 존재할 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/SphereCollider.html)

<a id="mesh-collider"></a>

## Mesh Collider · 메시 충돌체

메시 모양을 이용하는 일반 물리 충돌체입니다. Unity 기본 Cloth의 충돌 목록에는 등록할 수 없습니다. 사람이 정교하게 보인다는 것과 천이 그 몸을 충돌 검사한다는 것은 별개입니다.

<a id="box-collider"></a>

## Box Collider · 상자 충돌체

상자 모양의 일반 물리 충돌체입니다. 기본 Cloth의 Sphere/Capsule 목록에 직접 등록하는 종류가 아니므로 바닥에 있다는 이유만으로 천을 막지 않습니다.

<a id="capsule-list"></a>

## Capsule Colliders · 캡슐 목록

이 Cloth가 충돌할 Capsule Collider 참조들을 넣는 목록입니다. Size는 칸 수, Element는 한 칸입니다. 씬에 만드는 것과 이 목록에 드래그해 연결하는 것은 별도 작업입니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-capsuleColliders.html)

<a id="sphere-list"></a>

## Sphere Colliders · 구 쌍 목록

이 Cloth가 충돌할 구 쌍을 넣는 목록입니다. 한 칸마다 First와 Second를 지정합니다. 단일 구는 First만 채우고 Second는 None으로 둡니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-sphereColliders.html)

<a id="sphere-pair"></a>

## ClothSphereColliderPair · First · Second · Conic Capsule

구 하나 또는 두 구를 이용해 Cloth의 충돌 모양을 만드는 항목입니다. 두 구를 넣으면 구 사이까지 이어진 캡슐이 되며 양쪽 굵기를 다르게 만들 수 있습니다. First와 Second는 그 두 구를 가리키는 슬롯 이름입니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/ClothSphereColliderPair.html)

<a id="radius"></a>

## Radius · 반지름

중심에서 둥근 경계까지의 거리입니다. 구나 캡슐의 충돌 크기를 정합니다. Cloth의 Brush Radius는 붓 범위이므로 무엇의 반지름인지 함께 읽습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider-radius.html)

<a id="collider-center"></a>

## Collider Center · 충돌체 중심

충돌체가 붙은 물체의 로컬 좌표에서 중심이 있는 위치입니다. 물체 전체의 Position을 움직이는 것과 달리 그 안의 충돌 모양을 옮깁니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider-center.html)

<a id="collider-height"></a>

## Capsule Height · 캡슐 높이

캡슐 양 끝을 포함한 전체 길이입니다. 반지름과 함께 설정하며, 실제 세계에서의 크기는 물체의 Scale 영향도 받습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider-height.html)

<a id="collider-direction"></a>

## Capsule Direction · 캡슐 방향

캡슐의 긴 방향으로 사용할 로컬 X·Y·Z축을 고르는 항목입니다. 물체 자체를 회전하면 이 축의 세계 방향도 바뀝니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider-direction.html)

<a id="edit-collider"></a>

## Edit Collider · 충돌체 편집

Scene에서 충돌체의 윤곽과 손잡이를 직접 조절하는 도구입니다. 캡슐 충돌체를 바꾸어도 캐릭터의 그림용 메시가 함께 바뀌는 것은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/CapsuleCollider.html)

<a id="continuous"></a>

## Use Continuous Collision · 연속 충돌 · enableContinuousCollision

현재 위치만 보는 것보다 이동 경로를 더 살펴 빠른 물체와의 접촉을 찾는 방식입니다. Cloth의 계산 비용이 증가하므로 기본 충돌 연결을 확인한 뒤 비교합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-enableContinuousCollision.html)

<a id="tunneling"></a>

## Tunneling · 터널링

한 계산 시점에는 장애물 앞, 다음 시점에는 뒤에 있어 중간 접촉을 놓치고 통과하는 현상입니다. 빠른 움직임에서 나타날 수 있고 연속 충돌이 이를 줄이는 데 쓰입니다.

<a id="virtual"></a>

## Use Virtual Particles · 가상 입자

충돌 검사 때 삼각형 안에 추가 표본점을 사용해 면 사이의 접촉을 보완합니다. 그림용 메시의 정점이나 실제로 접을 수 있는 주름 수가 늘어나는 기능은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-useVirtualParticles.html)

<a id="solver"></a>

## Solver · 솔버

현재 상태가 여러 제약을 만족하도록 계산하는 부분입니다. 반복해서 오차를 줄이며, 반복 횟수가 늘면 계산 시간도 필요합니다.

<a id="solver-frequency"></a>

## Solver Frequency · Cloth Solver Frequency · 솔버 빈도

Cloth 솔버의 초당 반복 계산 수입니다. 공식 예에서 240회/초는 60FPS일 때 프레임당 약 4회에 해당합니다. FPS를 강제로 정하는 설정은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-clothSolverFrequency.html)

<a id="sleep"></a>

## Sleep Threshold · 휴면 기준 속도

점들의 움직임이 충분히 작아 천을 쉬는 상태로 판단할 때 사용하는 속도 기준입니다. Max Distance 0으로 고정하는 것과는 목적이 다릅니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-sleepThreshold.html)

<a id="self-collision"></a>

## Self-Collision · 자기 충돌

한 Cloth의 서로 다른 부분이 겹치는 것을 줄이는 입자 간 충돌입니다. 몸과의 충돌을 설정하는 Capsule Colliders와 별개입니다. 충돌 대상 점과 거리·강성을 함께 설정합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-selfCollisionDistance.html)

<a id="inter-collision"></a>

## Inter-Collision · 천 사이 충돌

서로 다른 Cloth에 속한 입자 사이의 충돌입니다. 대상 점 선택과 프로젝트의 관련 설정을 함께 확인합니다. 한 Cloth의 자기 충돌 값을 높이는 것만으로 같은 기능이 되지 않습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Physics-interCollisionDistance.html)

<a id="inter-enabled"></a>

## Enable Inter-Collision · 천 사이 충돌 사용

Physics 설정의 Cloth 탭에서 다른 Cloth끼리의 충돌 기능을 켜는 항목입니다. 충돌에 참여할 점은 각 Cloth에서 별도로 선택합니다. [공식 설정 설명](https://docs.unity3d.com/6000.6/Documentation/Manual/class-PhysicsManager.html)

<a id="inter-distance"></a>

## Inter-Collision Distance · 천 사이 충돌 거리

서로 다른 Cloth의 충돌 대상 입자가 유지하도록 하는 최소 간격입니다. 같은 Cloth 내부의 Self-Collision Distance와 구별합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Physics-interCollisionDistance.html)

<a id="inter-stiffness"></a>

## Inter-Collision Stiffness · 천 사이 충돌 강성

서로 다른 Cloth의 입자가 너무 가까워졌을 때 떼어 놓는 반응의 강도입니다. 겹침을 줄이지만 값을 높이는 것만으로 모든 관통이 해결되지는 않습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Physics-interCollisionStiffness.html)

<a id="self-distance"></a>

## Self-Collision Distance · 자기 충돌 거리

자기 충돌에서 점들이 확보하려는 최소 간격입니다. 원래 가까운 점 사이보다 크게 잡으면 다른 거리 제약과 충돌해 떨릴 수 있습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-selfCollisionDistance.html)

<a id="self-stiffness"></a>

## Self-Collision Stiffness · 자기 충돌 강성

자기 충돌에서 서로 겹친 점들을 떼어 놓는 반응의 강도입니다. 이 값만 정하지 말고 충돌 대상 점과 간격도 확인합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-selfCollisionStiffness.html)

<a id="surface-penetration"></a>

## Surface Penetration · 표면 침투 · Backstop

스키닝된 기준 표면의 뒤쪽으로 점이 파고드는 것을 제한하는 설정입니다. 표면의 바깥 방향인 법선을 사용합니다. 별도 Body 메시를 통째로 충돌 대상으로 등록하는 기능은 아닙니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/ClothSkinningCoefficient-collisionSphereDistance.html)

<a id="constraints-tool"></a>

## Edit Constraints · Edit cloth constraints · 제약 편집

천의 각 점에 Max Distance와 Surface Penetration 값을 정하는 편집 도구입니다. Inspector의 버튼을 누르면 Scene에 점들과 Cloth Constraints 도구판이 나타납니다.

<a id="select"></a>

## Select · Cloth 점 선택

점을 클릭하거나 사각형으로 감싸 고른 뒤 같은 제약값을 입력하는 방식입니다. 숫자를 바꾸면 현재 선택된 점들이 함께 바뀝니다.

<a id="paint"></a>

## Paint · Cloth 페인팅 · 칠하기

붓을 움직여 지나간 점에 제약값을 기록하는 방식입니다. 색 텍스처를 칠하는 작업이나 뼈 가중치를 칠하는 작업과 구별합니다.

<a id="gradient"></a>

## Gradient Tool · 그라데이션 도구

선택한 점들의 값을 화면 왼쪽에서 오른쪽으로 점차 바꾸는 도구입니다. Gradient Start와 End는 양 끝의 값이며 Scene의 2D 보기에서 사용합니다.

<a id="brush-radius"></a>

## Brush Radius · 붓 반지름

한 번의 칠하기가 닿는 범위를 정합니다. 크게 하면 넓게 칠할 수 있지만 작은 고정부까지 바꿀 수 있습니다.

<a id="constraint-size"></a>

## Constraint Size · 제약점 표시 크기

Scene에서 Cloth 점을 얼마나 크게 표시할지 정합니다. 고르기 편하게 만드는 표시 설정이며 물리 거리나 천 두께는 바꾸지 않습니다.

<a id="visualization"></a>

## Visualization · 시각화 · 색 범례

어떤 값을 눈에 보이게 표시할지 정하는 기능입니다. 색 범례는 색과 값의 대응표입니다. 선택한 속성과 현재 값 범위에 따라 의미가 달라질 수 있어 색 하나만 외우면 안 됩니다.

<a id="backfaces"></a>

## Manipulate Backfaces · 뒷면 점 조작

카메라에서 뒤쪽을 향하거나 가려진 면의 점도 조작 대상으로 포함하는 설정입니다. 옷 뒤까지 함께 칠할 때 쓰며 앞면만 고칠 때는 꺼야 범위를 좁히기 쉽습니다.

<a id="collision-tool"></a>

## Edit Collision Particles · 충돌 입자 편집

자기 충돌과 천 사이 충돌에 참여할 점을 고르는 도구입니다. Max Distance를 칠하는 Edit Constraints와 별도입니다.

<a id="collision-selection"></a>

## Self-Collision and Inter-Collision · 충돌 참여 체크

선택한 점을 자기 충돌·천 사이 충돌에 사용할 집합에 넣는 체크입니다. 이 체크만으로 모든 관련 거리와 강성 설정이 자동 완료되지는 않습니다.

<a id="rest-shape"></a>

## Rest Configuration · 기준 모양

변형시키기 전의 점 배치와 간격입니다. 자기 충돌 거리와 비교할 때 이 간격이 중요합니다. 현재 애니메이션 자세나 Bind Pose라는 말과 항상 같은 뜻으로 쓰지는 않습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-selfCollisionDistance.html)

<a id="coefficients"></a>

## ClothSkinningCoefficient · Cloth.coefficients

Cloth 점마다 저장된 Max Distance·표면 침투 제약 값의 자료입니다. 뼈별 영향 비율인 Skin Weight와 다른 자료이며 원본 메시 정점 번호와의 대응도 확인해야 합니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Cloth-coefficients.html)

<a id="offscreen"></a>

## Update When Offscreen · 화면 밖 갱신

Skinned Mesh Renderer가 카메라에 보이지 않을 때도 갱신할지 정하는 설정입니다. Cloth가 카메라 밖에 갔다 돌아올 때 이상하면 Bounds와 함께 확인합니다. 계속 갱신하면 비용도 남습니다.

[공식 정의](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/SkinnedMeshRenderer-updateWhenOffscreen.html)

<a id="wind-zone"></a>

## Wind Zone · 바람 영역

나무와 파티클 등의 바람 표현에 쓰는 Unity 컴포넌트입니다. Cloth 실습에서는 이 물체를 추가하는 데서 끝내지 않고 External/Random Acceleration으로 천의 반응을 먼저 확인합니다.

<a id="render-face"></a>

## Render Face · Front · Back · Both

URP 재질이 삼각형의 어느 면을 그릴지 정하는 설정입니다. Front는 앞, Back은 뒤, Both는 양면입니다. Both를 골라도 천에 물리적 두께가 생기는 것은 아닙니다.
