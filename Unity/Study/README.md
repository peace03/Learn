# VARCO × Unity URP 학습 길잡이

이 프로젝트로 **3D 모델을 가져와 움직이고, 재질과 빛을 조절해 전시 화면을 만드는 과정**을 배웁니다. 처음에는 눈으로 비교하고, 다음에는 그 결과가 나오는 원리를 읽습니다.

## 공부 방법

1. 처음 배우면 준비 A → B → C부터 읽은 뒤 01~18장으로 갑니다. 04장 다음에는 04A의 USD 기초를 읽습니다. 각 장의 실습은 설명을 읽은 직후 실행합니다.
2. 원본 대신 `Assets/_Study`에 만든 복사본으로 실습합니다. 폴더 생성 방법은 02장에 있습니다.
3. 값을 하나 바꾸고 결과 하나를 확인합니다. 여러 값을 한꺼번에 바꾸면 원인을 찾기 어렵습니다.
4. 장 끝의 확인 질문을 자기 말로 답하면 다음 장으로 갑니다.

**쉬운 말은 입구이고, 정확한 조건이 깊이입니다.** “Avatar는 뼈 번역표”라고 이해한 뒤, 같은 리그인지·Humanoid가 유효한지·실제로 뼈가 움직이는지까지 확인합니다.

## 모르는 말 때문에 막혔을 때

전문 용어는 [전체 용어 색인](90_참고/용어_사전.md)에서 `Ctrl+F`로 찾습니다. 사전은 뜻과 예를 찾는 곳이고, 원리는 준비 장과 각 본문을 순서대로 읽습니다. 15장부터 시작해 모든 코드를 한 번에 이해하려 하지 않아도 됩니다.

각 장에서 **선수 개념 → 원리 → 조작 → 관찰 → 확인 질문**을 읽습니다. 실습에서 기대한 결과가 없으면 다음 변환을 반복하기 전에 17장의 증상 표를 봅니다. [보강 내역](90_참고/설명_누락_점검.md)에서 무엇을 추가했는지도 찾을 수 있습니다.

## 먼저 알아둘 현재 상태

- 주 실습 씬은 `Lab_Varco3D_01`. 기본 빌드 씬 목록에는 `SampleScene`만 있습니다.
- 현재 Walk FBX는 **Generic**, Runing FBX는 **Humanoid** 설정입니다. 이름에 Walk/Run이 있다고 설정까지 같지는 않습니다.
- 작성 중 씬 저장 변경을 다시 확인했습니다. Chibi Robot이 추가되고 Walk는 꺼져 있으므로, Walk 실습 때는 복사 씬에서 해당 루트를 켭니다. 최근 파일 상태는 [에셋·설정 근거](90_참고/에셋과설정_근거.md)에 적었습니다.
- `Lab_Canvas`의 스크립트 6개는 조사한 씬·프리팹에 연결되어 있지 않습니다. 13장은 직접 연결하는 연습입니다.
- 변환 도구는 같은 이름의 결과물을 지우고 다시 만들 수 있습니다. 11장의 백업 절차를 먼저 읽습니다.
- `05.Editor`는 Unity가 특별 취급하는 정확한 폴더명 `Editor`와 다릅니다. 현재 Editor 전용 코드의 빌드 분리 문제는 18장에서 다룹니다.

## 이 자료에서 쓰는 표시

| 표시 | 뜻 |
|---|---|
| 파일 확인 | 코드·설정·씬 파일에 실제로 기록되어 있음 |
| 원리 | Unity와 3D 그래픽의 일반적인 동작 설명 |
| 실습 | 독자가 복사본에서 실행할 절차. 이번 문서 작성 중 실행한 결과가 아님 |
| 확인 필요 | Editor의 실제 표시·재생·외관을 추가로 확인해야 함 |

분석일은 **2026-10-07**입니다. 프로젝트는 `6000.6.0f1`, URP는 `17.6.0`입니다. 메뉴는 영어 이름을 기준으로 적었습니다. Unity 6 공식 문서와 로컬 코드를 대조했으나 현재 Editor를 직접 클릭하거나 Play·변환·빌드하지 않았습니다. 저장하지 않은 Editor 상태와 파일 내용은 다를 수 있습니다.
