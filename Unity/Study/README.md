## 자료를 추가할 때

- 새 내용은 해당 주제의 기능 폴더에 넣고 그 주제 README에 링크합니다.
- 공통 용어는 전체 사전에서 찾습니다. 기능 문서에 다른 주제의 설명 전체를 복사하지 않습니다.
- VARCO 전용 메뉴·코드 분석은 VARCO 프로젝트 아래에 넣습니다. 여러 기능을 조합한 과제는 종합 실습에 넣습니다.
