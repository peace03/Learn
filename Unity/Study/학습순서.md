# VARCO × Unity URP 학습 길잡이

이 프로젝트로 **3D 모델을 가져와 움직이고, 재질과 빛을 조절해 전시 화면을 만드는 과정**을 배웁니다. 처음에는 눈으로 비교하고, 다음에는 그 결과가 나오는 원리를 읽습니다.

## 공부 방법

1. 처음 배우면 준비 A → B → C부터 읽은 뒤 아래 표의 순서로 진행합니다. 각 실습은 설명을 읽은 직후 실행합니다. 필요한 기능만 찾을 때는 [주제별 목차](README.md)를 사용합니다.
2. 원본 대신 `Assets/_Study`에 만든 복사본으로 실습합니다. 폴더 생성 방법은 [Unity 첫 실습 문서](00_기초/Unity_기본조작.md)에 있습니다.
3. 값을 하나 바꾸고 결과 하나를 확인합니다. 여러 값을 한꺼번에 바꾸면 원인을 찾기 어렵습니다.
4. 본문이나 [기능별 확인 질문](95_종합실습/기능별_확인질문.md)에 자기 말로 답한 뒤 다음 단계로 갑니다.

**쉬운 말은 입구이고, 정확한 조건이 깊이입니다.** “Avatar는 뼈 번역표”라고 이해한 뒤, 같은 리그인지·Humanoid가 유효한지·실제로 뼈가 움직이는지까지 확인합니다.

## 모르는 말 때문에 막혔을 때

전문 용어는 [전체 용어 색인](90_용어사전/README.md)에서 `Ctrl+F`로 찾습니다. 사전은 뜻과 예를 찾는 곳이고, 원리는 준비 장과 각 본문을 순서대로 읽습니다. [변환 알고리즘과 설계 문서](85_VARCO프로젝트/02_Bridge와변환/개념과원리.md)부터 시작해 모든 코드를 한 번에 이해하려 하지 않아도 됩니다.

일반 문서에서는 선수 개념·원리·실습·확인 기준을 읽습니다. Cloth는 기능별로 **방법 → 개념과 원리**를 읽고, 모르는 말은 용어 사전에서 찾습니다. 실습에서 기대한 결과가 없으면 다음 변환을 반복하기 전에 [문제 해결 사전 문서](95_종합실습/문제해결.md)의 증상 표를 봅니다. [보강 내역](99_참고/설명_누락_점검.md)에서 무엇을 추가했는지도 찾을 수 있습니다.

## 이 자료에서 쓰는 표시

| 표시 | 뜻 |
|---|---|
| 파일 확인 | 코드·설정·씬 파일에 실제로 기록되어 있음 |
| 원리 | Unity와 3D 그래픽의 일반적인 동작 설명 |
| 실습 | 독자가 복사본에서 실행할 절차. 이번 문서 작성 중 실행한 결과가 아님 |
| 확인 필요 | Editor의 실제 표시·재생·외관을 추가로 확인해야 함 |

분석일은 **2026-10-07**입니다. 프로젝트는 `6000.6.0f1`, URP는 `17.6.0`입니다. 메뉴는 영어 이름을 기준으로 적었습니다. Unity 6 공식 문서와 로컬 코드를 대조했으나 현재 Editor를 직접 클릭하거나 Play·변환·빌드하지 않았습니다. 저장하지 않은 Editor 상태와 파일 내용은 다를 수 있습니다.
