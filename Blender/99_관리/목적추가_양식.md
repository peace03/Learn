# 새 목적 추가 양식

이 문서는 빈 틀입니다. 아직 요청하지 않은 작업의 설명서를 미리 만들지 않습니다. 실제 목적이 생기면 `10_목적별/002_짧은목적명/`에 필요한 단계만 작성합니다. 짧은 일은 한 문서로 충분하며 억지로 나누지 않습니다.

## 단계 본문 틀

```text
# 단계 제목

목표: 이 단계를 끝내면 무엇이 달라지는가.
먼저 알아둘 말: 뜻을 한 문장으로 풀고 사전 링크를 붙인다.
원리: 입력이 어떤 계산을 거쳐 결과가 되는지 설명한다.
시작 상태: 창, 모드, 선택 대상, 선행 설정을 적는다.

1. 어느 창의 어떤 이름을 클릭한다.
2. 무엇을 먼저 선택하고 무엇을 마지막에 선택한다.
3. 어디에서 어디로 드래그하는지 적는다.
4. 필요한 숫자의 단위와 그 숫자를 고른 이유를 적는다.

정상 결과: 화면·목록·숫자로 확인할 조건.
실패 증상: 가능한 원인과 최소 복구.
저장/복구 지점: 원본 보존과 되돌리는 방법.
이전 단계 / 목적 목차 / 다음 단계.
```

## 용어를 함께 추가하는 규칙

단어를 다른 전문 용어로만 바꾸어 정의하지 않습니다. ‘[스키닝](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#skinning)은 [웨이트](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#weight)를 [리그](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#rig)에 바인딩’처럼 쓰는 대신 ‘표면의 각 점이 어느 뼈를 얼마나 따라갈지 정해 연결’처럼 먼저 풀이합니다. 필요한 하위 용어는 각각 독립 항목과 링크를 만듭니다.

영문·약어·한글 별칭을 통합 사전에 함께 싣습니다. 같은 말이 다른 뜻으로 쓰이면 용도를 나눕니다. 예: [Geometry Nodes](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#geometry-nodes)의 [Domain](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#domain), [유체](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#fluid)의 Domain. 숫자 예시와 실제 측정값을 구분합니다.

작성 뒤 새 목적을 [목적 목록](../10_목적별/README.md)에 추가하고, 공통 개념·사전·이전/다음 링크를 확인합니다. 실제 클릭해 본 범위와 문서·[데이터](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)로만 확인한 범위를 따로 기록합니다.
