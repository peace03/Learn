# 새 방법 추가 양식

새 요청이 생기면 `10_방법/003_짧은목적명/`처럼 번호를 붙입니다. 현재 자료에서는 001과 002를 사용합니다.

```text
003_짧은목적명/
  방법.md
  개념과원리/
    README.md
    필요한 경우에만 추가 설명.md
```

## 방법.md에 적을 것

목표 한 문장 → 필요한 준비 상태 → 번호가 있는 클릭·입력 순서 → 눈으로 확인할 완료 조건 → 짧은 복구 → 관련 개념·원리 링크.

클릭 순서는 **창 이름, 모드, 대상 이름, 먼저/마지막 선택, 버튼, 입력값**을 분명히 적습니다. 드래그는 시작과 끝을 적습니다. 기존 파일을 덮어쓰는지, 몸 전체와 팔 중 어디를 바꾸는지도 시작 부분에 적습니다.

공식·깊은 이유·여러 대안 비교는 방법 본문에 넣지 않습니다. 따라 하는 데 필요한 제한 조건은 생략하지 않습니다. 예를 들어 ‘팔만 수정’이라고 적고 Body 전체를 대칭화하는 절차를 넣으면 안 됩니다.

## 개념과원리/README.md에 적을 것

1. 이 방법에서 중요한 전문 용어를 쉬운 문장으로 풉니다.
2. 입력 → 계산 → 결과를 설명합니다. 필요하면 작은 좌표 예를 씁니다.
3. 비슷한 기능과 구별합니다.
4. 현재 모델에서 확인한 사실과 일반적인 원리를 구분합니다.
5. 실제 실행한 검증과 문서·수학으로만 확인한 범위를 적습니다.
6. 공식 근거와 공통 개념·용어사전으로 연결합니다.

전문 용어가 새로 나오면 [용어사전](../90_용어사전/README.md)에도 한글·영문 별칭을 등록합니다. 다른 전문 용어만으로 정의하지 말고 그 용어도 연결합니다. 기존에 있는 항목은 새로 중복 작성하지 않습니다.

마지막으로 루트 [README 목차](../README.md)와 [방법 목록](../10_방법/README.md)에 **방법 → 그 아래 개념·원리** 순서로 링크합니다. 파일 이동 뒤 모든 내부 링크를 검사합니다.
