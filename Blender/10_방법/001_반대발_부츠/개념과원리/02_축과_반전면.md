# 상세 해설: 02. Z축 반전인지 X축 반전인지 판단하기

먼저 [짧은 따라 하기](../방법.md)를 진행한 뒤 필요할 때 읽는 상세 해설입니다. 아래 모델 관찰값은 2026-10-07의 기록입니다. 현재 파일의 이름·뼈·상태는 다를 수 있습니다.

**이 [장면](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)의 정답은 X 방향 [거울 반전](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)입니다.** ‘Z축을 기준으로’라는 말만으로는 [회전](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)인지, Z축을 포함하는 세로 거울면인지, Z [좌표](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)를 뒤집는지 구분할 수 없습니다. 화면에서 이루려는 결과를 먼저 수로 표현합니다.

## 바닥부터 이해하기

좌표는 ‘기준점에서 어느 방향으로 얼마나 떨어졌나’를 적은 수입니다. [Blender](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender) 전역 공간의 위아래는 Z입니다. 현재 몸의 좌우는 X로 나뉩니다. Y는 앞뒤 방향입니다. 축의 +/− 방향은 화면 오른쪽 위 축 표시를 읽습니다.

```text
정면에서 본 현재 장면

                 +Z 위
                   ↑
  원본 부츠        │        새 부츠
   X 음수    ←     │     →  X 양수
                   │
              X=0 세로 중심면

거울면은 종이 안팎의 Y 방향으로도 펼쳐진 YZ 평면이다.
```

X=0 [평면](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#plane)에 거울을 놓으면 점 `(x,y,z)`는 `(-x,y,z)`가 됩니다. 높이와 발끝 앞뒤 방향은 유지되고 좌우만 바뀝니다. 중심이 X=c라면 `x' = 2c - x`입니다. 이번에는 c=0입니다.

| 명령의 뜻 | 원점 기준 좌표 변화 | 이번 부츠 결과 |
|---|---|---|
| X 거울 반전 | (x,y,z) → (-x,y,z) | 반대 발 쪽으로 가고 좌우 모양도 뒤집힘 |
| Z 거울 반전 | (x,y,z) → (x,y,-z) | 위아래가 뒤집힘 |
| Z축 180도 회전 | (x,y,z) → (-x,-y,z) | 좌우와 앞뒤가 함께 돌아 발끝도 반대로 향함 |
| X 방향 이동만 | (x,y,z) → (x+d,y,z) | 자리는 바뀌지만 부츠의 안쪽·바깥쪽 모양은 그대로 |

거울 반전의 축은 **거울면에 수직인 방향**입니다. ‘Z축이 들어 있는 세로면’과 ‘Z 반전’은 다른 말입니다. [공식 Mirror 설명](https://docs.blender.org/manual/en/5.1/modeling/meshes/editing/mesh/mirror.html)을 참고할 수 있습니다.

## 직접 판단하는 클릭 순서

1. [View](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view) → [Viewpoint](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#viewpoint) → **[Front](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#front)**를 클릭합니다. 원근 상태라면 View → [Perspective](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#perspective)/[Orthographic](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#orthographic)으로 정투영을 [선택](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)합니다.
2. [Outliner](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner) 검색을 비워 몸과 양쪽 발을 함께 봅니다. 한쪽 부츠만 크게 보이면 휠을 뒤로 돌려 축소합니다.
3. 오른쪽 위 축 표시에서 Z가 위쪽인지 확인합니다.
4. 양발의 높이는 비슷하고 X 방향으로 벌어져 있는지 확인합니다.
5. 몸 중심이 X=0 부근인지 확인합니다. 이번 관찰에서는 몸 경계가 약 -0.4992~+0.4992여서 중심 기준으로 적합했습니다.

다른 모델이 누워 있거나 옆으로 돌아 있으면 축 선택부터 다시 해야 합니다. 현재 부츠는 자체 회전이 있으므로 **[Global](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global) X**를 사용합니다. [Local](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#local) X는 부츠에 붙어 돌아간 방향입니다.

[피벗](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)도 중요합니다. 부츠 자신의 중심에서 뒤집으면 모양만 뒤집히고 반대 발로 충분히 이동하지 않습니다. 다음 단계에서 [3D Cursor](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#cursor)를 몸의 중심인 원점에 놓아 피벗으로 사용합니다. 물체의 [Origin](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#origin)을 옮길 필요는 없습니다.
