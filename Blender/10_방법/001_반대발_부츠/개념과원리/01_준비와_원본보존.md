# 상세 해설: 01. 현재 상태를 확인하고 원본 보존하기

먼저 [짧은 따라 하기](../방법.md)를 진행한 뒤 필요할 때 읽는 상세 해설입니다. 아래 모델 관찰값은 2026-10-07의 기록입니다. 현재 파일의 이름·뼈·상태는 다를 수 있습니다.

목표는 **현재 작업 내용이 들어 있는 별도 파일**을 만드는 것입니다. 열려 있는 파일에는 아직 저장하지 않은 변경이 있었습니다. 예전 디스크 파일을 다시 열면 그 변경을 잃을 수 있으므로 현재 상태에서 [Save As](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#save-as)를 사용합니다.

## 클릭 순서

1. [Blender](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender) 위쪽 **File → Save As**를 클릭합니다.
2. [File Browser](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#file-browser)에서 현재 파일이 있는 폴더를 유지합니다. 파일 이름만 `Boots_Opposite_Study.blend`처럼 새 이름으로 바꿉니다. 이미 같은 파일이 있으면 끝에 번호를 붙입니다.
3. **Save As**를 클릭합니다. 덮어쓰기 경고가 뜨면 기존 원본 이름이 아닌지 확인합니다.
4. 창 제목 또는 File → Save As의 경로 표시로 현재 작업 파일 이름이 새 이름인지 확인합니다. 확인용으로 창을 다시 열었다면 저장하지 않고 Cancel로 닫습니다.
5. [Layout](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#layout) 탭을 클릭합니다. [Outliner](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner) 검색 칸에 `Boots1-1`을 입력하고 해당 이름을 한 번 클릭합니다.
6. 마우스를 [3D Viewport](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport)로 옮깁니다. 왼쪽 위 [모드](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mode) 메뉴에서 **[Object Mode](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode)**를 고릅니다.
7. **[View](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view) → [Frame Selected](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#frame-selected)**를 클릭합니다. 부츠가 화면 중심에 크게 보이면 성공입니다.
8. N → **[Item](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item) → [Transform](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)**에서 위치·[회전](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation) 방식·[Scale](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#scale)을 읽습니다. 원본 이름과 주요 숫자를 기록해 둡니다.

현재 확인한 값은 [실습 첫 페이지](../%EB%B0%A9%EB%B2%95.md)의 표와 같습니다. 숫자가 달라졌다면 이 문서에 맞추려고 원본 값을 덮어쓰지 않습니다. 다른 파일·다른 [선택](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)·사용자가 한 수정 중 무엇인지 먼저 확인합니다.

## 왜 별도 파일이 필요한가

[Undo](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#undo)는 현재 작업 기록을 되돌리는 기능입니다. 프로그램을 다시 열거나 기록 범위를 넘으면 예전 상태를 되찾지 못할 수 있습니다. 새 파일은 그 시점의 작업을 따로 보관합니다. 원본 파일을 다시 여는 것과 현재 상태를 새 이름으로 저장하는 것은 다릅니다.

## 정상 결과와 복구

| 확인 | 정상 | 다를 때 |
|---|---|---|
| 파일 이름 | 새 작업 이름 | 원본이면 작업 전 Save As 다시 실행 |
| 선택 | `Boots1-1` 하나 | Outliner에서 다시 선택 |
| 모드 | Object Mode | 왼쪽 위 메뉴로 전환 |
| 보이는 물체 | 긴 부츠 | 동명이거나 다른 [오브젝트](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)인지 확인 |

[텍스처](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)·[캐시](../../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#cache) 같은 외부 파일은 그대로 참조할 수 있습니다. 이번 단계는 복사한 blend에서 배치 작업을 안전하게 시작하는 목적입니다. 전체 파일 전달 방법은 [파일 개념](../../../20_%EA%B3%B5%ED%86%B5%EA%B0%9C%EB%85%90/14_%ED%8C%8C%EC%9D%BC_%EC%9E%90%EB%8F%99%ED%99%94_%EC%84%B1%EB%8A%A5.md)에서 다룹니다.
