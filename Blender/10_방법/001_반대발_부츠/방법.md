# 반대 발 부츠 만들기: 따라 하기

목표: 기존 부츠를 보존하고 반대편에 부츠 하나를 만듭니다.

준비: Z가 위쪽이고 몸의 중심이 X=0인 모델. 2026-10-07 예시는 `Boots1-1`입니다. **2026-10-08 파일에는 `Boots-L`과 `Boots-R`이 이미 있으므로, 이 파일에서 연습하면 부츠가 겹쳐 생깁니다. 연습 복사본에서만 진행합니다.**

## 클릭 순서

1. **File → Save As**에서 새 파일 이름으로 저장합니다.
2. 뷰포트 왼쪽 위를 **Object Mode**로 바꿉니다. Outliner에서 복사할 부츠 하나만 클릭합니다.
3. 마우스를 뷰포트에 두고 **Shift+D → 오른쪽 클릭 → F2**를 누릅니다. 이름을 `Boots_Opposite`로 입력합니다.
4. 뷰포트 위쪽 방향 메뉴를 **Global**로 고릅니다.
5. **Shift+S → Cursor to World Origin**을 선택합니다.
6. 위쪽 **Transform Pivot Point → 3D Cursor**를 선택합니다.
7. **Ctrl+M → X → Enter**를 누릅니다. X는 한 번만 누릅니다.
8. **Transform Pivot Point → Median Point**로 되돌립니다.
9. **View → Viewpoint → Front / Right / Top**을 차례로 보며 발끝 방향·밑창 높이·발목 관통을 확인합니다.
10. 위치가 조금 다르면 **G → 필요한 축 → 작은 수 → Enter**로 새 부츠만 조정합니다. 잘못 움직이면 Ctrl+Z합니다.
11. 새 부츠만 선택한 Object Mode에서 **Ctrl+A → Scale**을 선택합니다. 바로 F9를 눌러 **Corrective Flip Normals**가 켜져 있는지 확인합니다. N → Item의 Scale이 모두 1이고 모양은 같아야 합니다.
12. 오른쪽 위 **Viewport Overlays → Face Orientation**으로 원본과 겉면 방향을 비교하고 다시 끕니다. **Material Preview**로 무늬를 확인합니다. 이상하면 [표면 상세 해설](개념과원리/05_스케일_법선_UV.md)을 봅니다.
13. **Ctrl+S**로 새 작업 파일에 저장합니다.

## 완료 확인

- 원본과 새 부츠가 각각 선택됩니다.
- 새 부츠가 반대편에 있고 발끝이 원본과 같은 앞쪽을 향합니다.
- 피벗이 Median Point로 돌아왔습니다.
- 현재 예시에는 발 뼈가 없으므로 ‘걸을 때 따라 움직이는 연결’까지 완료한 것은 아닙니다.

잘못 뒤집혔으면 **Ctrl+Z → Global·커서 원점·X 입력**을 확인합니다. 위아래가 뒤집혔으면 Z를 눌렀는지 확인합니다.
