# Body 양팔 늘리기: 관련 개념과 원리

클릭만 따라 하려면 [방법 문서](../방법.md)로 돌아갑니다. 여기서는 선택한 방법의 이유와 한계를 설명합니다.

## 1. 같은 비율과 같은 모양은 다르다

왼팔이 30, 오른팔이 31인 상태에서 둘 다 1.1배로 늘리면 33과 34.1입니다. 같은 비율을 썼지만 길이는 다릅니다. 좌우 구조가 이미 다르면 양쪽을 함께 선택해 S → X로 확대하는 것만으로 동일한 팔이 되지 않습니다.

이번 요청에서는 사용자가 **한쪽 기준으로 길이·모양을 통일하고 Body 전체 대칭도 허용**했습니다. 따라서 독립적인 양팔을 각각 수정하지 않고 한쪽 자료에서 양쪽 결과를 계산합니다.

## 2. 지금 Body에서 X Mirror만 켜면 충분하지 않은 이유

메시는 점인 [정점](../../../90_용어사전/03_메시와모델링.md#vertex)과 그 연결로 만든 표면입니다. 편집 모드의 [X Mirror](../../../90_용어사전/03_메시와모델링.md#mesh-symmetry)는 기존 반대쪽에서 대응하는 정점을 찾아 함께 움직이는 기능입니다. 닮아 보이는 점이 근처에 있다는 것만으로 항상 대응하지 않습니다.

확인 당시 편집 중인 Body는 정점 **2,274개**, 면 **2,249개**였습니다. X 좌표를 반대로 바꾼 위치에서 거리 `0.00001` 이내에 점이 있는 경우는 전체 6개였고, `|x|>0.18` 영역에서는 0개였습니다. 6개는 자기 자신과 가까운 중심점도 포함할 수 있어 좌우 정점쌍 수를 뜻하지 않습니다. 이 검사는 위치 대응의 부족을 확인한 것이며 연결 구조의 대칭성을 증명한 검사는 아닙니다.

[Topology Mirror](../../../90_용어사전/03_메시와모델링.md#topology-mirror)는 점의 연결 구조를 이용합니다. 대응할 구조가 있는지 확인하지 않고 켜기만 하면 모든 비대칭 모델이 해결된다고 볼 수 없습니다. [Blender 공식 Tool Settings](https://docs.blender.org/manual/en/4.0/modeling/meshes/tools/tool_settings.html).

## 3. Mirror Modifier는 대응점을 찾는 대신 새 결과를 만든다

[Modifier](../../../90_용어사전/01_화면과데이터.md#modifier)는 원래 메시 위에 계산을 더하는 기능입니다. Mirror는 선택한 기준면 반대편에 같은 모양을 계산합니다. 이번 파일은 오브젝트 원점이 (0,0,0)이고 회전·크기가 기본 상태라, 로컬 X=0과 전역 X=0이 일치합니다.

원본 한 점이 `(x,y,z)`이면 반대편 점은 `(-x,y,z)`입니다. 한쪽 손이 `x=0.45`에서 `0.47`로 이동하면 반대쪽은 `-0.45`에서 `-0.47`로 갑니다. 두 쪽의 이동 거리는 각각 0.02입니다. 좌우의 대응하는 표면 길이도 거울 변환으로 보존됩니다. ‘길이’가 어느 뼈 구간을 뜻하는지 정하지 않은 상태에서 해부학적 팔 길이를 몇 cm라고 측정한 것은 아닙니다.

**Bisect X**를 켜면 X=0을 기준으로 한쪽을 계산에 사용하고 다른 쪽은 그 거울 결과로 표시합니다. Flip을 끈 기본 방향에서는 X 양수 쪽을 기준으로 합니다. 원래 반대편의 비대칭 자료는 모디파이어 적용 전 기본 메시에는 남을 수 있지만 최종 표시 결과에는 기준 쪽이 사용됩니다. [공식 Mirror Modifier](https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/mirror.html).

```text
기본 메시: 좌우가 조금 다른 Body
               ↓ Bisect X: 양수 쪽을 사용
             +X 반쪽
               ↓ Mirror X
결과:      -X 복제 │ +X 기준
                   X=0
```

이 계산은 **Body 전체**에 작용합니다. 팔뿐 아니라 몸통과 다리의 좌우 차이도 한쪽 기준으로 통일됩니다. 별도 Head·OutterJeogori·Boots 오브젝트에는 작용하지 않습니다. 사용자가 허용한 범위와 다른 모델에서는 그대로 적용하지 않습니다.

## 4. 피벗과 모디파이어 기준면을 구별한다

[Pivot](../../../90_용어사전/02_좌표와변환.md#pivot)은 수동 회전·확대의 중심입니다. Mirror Modifier는 기본적으로 **Object Origin과 로컬 축**을 기준으로 합니다. 3D Cursor를 움직여도 Mirror Object를 지정하지 않은 모디파이어의 기준면은 자동으로 따라가지 않습니다.

이전 부츠 방법은 커서 피벗을 쓰는 일회성 반전이었습니다. 이번 팔 방법은 계속 계산하는 모디파이어입니다. 비슷한 ‘Mirror’라는 이름 때문에 같은 기능으로 보지 않습니다.

[Merge](../../../90_용어사전/03_메시와모델링.md#mirror-merge)는 가까운 중앙 대응점을 연결하고, [Clipping](../../../90_용어사전/03_메시와모델링.md#mirror-clipping)은 중앙 점이 기준면을 넘는 편집을 제한합니다. 수치는 장면 크기에 따라 조정해야 합니다. 값 하나로 원래 있던 모든 구멍이 메워지는 것은 아닙니다.

## 5. 손은 옮기고 팔은 완만하게 늘린다

손 전체를 선택해 [평행 이동](../../../90_용어사전/02_좌표와변환.md#translation)하면 모든 손 정점에 같은 이동량이 더해집니다. 손 안의 두 점 A와 B에 같은 거리 d를 더하면 `(B+d)-(A+d)=B-A`이므로 손가락 사이 거리와 손 크기는 그대로입니다.

반면 손의 일부만 선택하면 선택된 점과 빠진 점 사이 거리가 달라져 손가락이 길어지거나 갈라져 보입니다. 그래서 **X-Ray로 뒤쪽 점까지 포함하고 손 전체를 선택**합니다.

[비례 편집](../../../90_용어사전/03_메시와모델링.md#proportional)은 선택 주변의 점에도 거리에 따라 약해지는 움직임을 줍니다. 손은 이동량 전체, 가까운 팔은 일부, 범위 밖 몸통은 0의 영향을 받게 하는 것입니다. **Smooth**는 변화가 완만하게 줄어드는 규칙이고 **Connected Only**는 표면의 연결을 따라 영향 거리를 계산합니다. 같은 Body의 몸통도 연결되어 있으므로 Connected Only를 켜도 반경이 너무 크면 몸통이 움직입니다. [공식 Proportional Editing](https://docs.blender.org/manual/sl/latest/editors/3dview/controls/proportional_editing.html).

방법의 이동량 0.02와 영향 크기 0.12는 현재 약 1 단위 폭의 모델에서 시작할 예시입니다. 선택한 손목 위치에 따라 범위를 조정합니다. 손 크기는 수학적으로 유지할 수 있어도 어느 팔 부위가 얼마나 늘어날지는 영향 범위와 메시 구조에 따라 달라집니다. 관절 위치까지 설계하려면 그 위치를 먼저 정해야 합니다.

양쪽에서 따로 비례 편집을 하는 것이 아닙니다. 기준 쪽에서 계산한 결과를 Mirror가 반대편에 복사하므로 두 쪽의 최종 모양이 맞습니다.

## 6. Apply를 나중으로 미루는 이유

모디파이어의 Apply는 결과를 기본 메시로 굳힙니다. 적용 전에는 기준 쪽을 고치면 반대쪽 결과가 계속 바뀝니다. 이번 방법은 그 상태로 저장합니다. 별도 원본 Body도 숨겨 남깁니다.

임의로 Origin을 옮기거나 전체 Rotation·Scale을 초기화하지 않습니다. 현재 좌표 조건이 다른 파일은 먼저 기준면을 정해야 합니다. 뼈·Shape Key가 이미 있는 캐릭터는 대칭으로 구조를 바꾸기 전에 기존 변형 자료와의 대응을 따로 검토합니다.

Mirror는 UV·재질 배치에도 영향을 줍니다. 한쪽 피부의 비대칭 무늬·글자·흉터를 보존하는 방법은 아닙니다. 의상은 별도 오브젝트이므로 Body 팔이 길어져도 소매는 자동으로 따라 늘어나지 않습니다.

## 7. 짧은 기능 비교

| 기능 | 작동 | 이번 선택 |
|---|---|---|
| 양팔 선택 + S X | 선택 좌표를 같은 배율로 확대 | 시작 좌우 차이·손 크기 변화가 남을 수 있음 |
| Edit Mode X Mirror | 기존 대응 정점도 함께 변환 | 현재 정점 대응이 부족해 기본 방법으로 쓰지 않음 |
| Topology Mirror | 연결 구조로 대응 관계 판단 | 현재 전체 대응을 확인하지 못함 |
| Symmetrize | 한쪽 구조를 지우고 다른 쪽을 반전 복사 | 기본 메시를 바꾸므로 이번 따라 하기에는 쓰지 않음 |
| Mirror + Bisect | 한쪽으로 좌우 결과를 계속 계산 | 이번 기본 방법 |

팔 일부만 선택한 Symmetrize를 장면에 적용하지 않고 메모리의 메시 복사본에서 시험했을 때, 열린 경계 에지가 48개에서 70개로 늘고 면에 붙지 않은 에지가 생겼습니다. 선택 범위를 잘라 대칭화하는 과정은 팔·몸통 연결까지 보장하지 않는다는 확인입니다. 이 시험을 사용자 모델에 실행하지 않았습니다. [공식 Symmetrize](https://docs.blender.org/manual/en/latest/modeling/meshes/editing/mesh/symmetrize.html).

## 8. 관찰과 검증 범위

확인한 파일: `Character_Boots6000QuadsEach_Retopo_20261008.blend`. Blender 5.2.1 LTS, Body Edit Mode, 선택된 정점 0, 원점·회전·크기 기본 상태. Body의 메시 사용자는 1, Shape Key와 Modifier는 없었고 정점 그룹 `Detail_HandsForearmsNeck`가 있었습니다. 장면의 뼈대는 치마용이었으며 Body를 움직이는 팔 리그는 확인되지 않았습니다.

Body의 양팔을 편 자세·정면·위 화면, 편집 중인 정점 자료와 설정을 읽었습니다. 설치된 5.2.1의 화면 구성 코드와 속성을 읽어 Options의 Mirror/Auto Merge, 비례 편집 펼침 메뉴의 Connected Only/Projected from View/Proportional Size도 확인했습니다. 문서 링크와 대칭·이동 계산을 검사합니다. **실제 Body 복제·모디파이어 추가·팔 늘리기·저장은 실행하지 않았습니다.** 작성 뒤에도 Body 정점 좌표·선택·모드·모디파이어가 처음 상태와 같았습니다. 그러므로 실제 클릭 후의 손목 형태·어깨·의상 맞춤은 방법 문서의 완료 검사를 직접 수행해야 합니다.
