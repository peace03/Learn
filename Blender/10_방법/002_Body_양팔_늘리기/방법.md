# Body 양팔을 같은 길이와 모양으로 늘리기: 따라 하기

**목표:** 한쪽 팔을 늘리면 반대쪽도 똑같이 늘어나게 만듭니다. 손 자체의 크기는 유지합니다.

**적용 범위:** 사용자 선택에 따라 **Body 전체를 X 양수 쪽 기준으로 대칭화**합니다. 몸통·다리의 기존 좌우 차이도 바뀝니다. 원본은 숨겨 보관합니다. 별도 머리·옷·부츠는 수정되지 않습니다.

기준: 2026-10-08의 `Body`, 양팔을 옆으로 편 자세, Location=(0,0,0), Rotation=(0,0,0), Scale=(1,1,1), 뼈 변형 없음. 이 조건이 다르면 [현재 조건 설명](개념과원리/README.md)을 먼저 확인합니다.

## 1. 작업 복사본 만들기

1. **File → Save As**에서 `Body_Arms_Study.blend` 같은 새 이름으로 저장합니다.
2. 뷰포트 왼쪽 위 모드 메뉴에서 **Object Mode**를 선택합니다.
3. Outliner에서 **Body 하나만** 클릭합니다. 마우스를 뷰포트로 옮깁니다.
4. **Shift+D → 오른쪽 클릭 → F2**를 누르고 이름을 `Body_ArmsStudy`로 입력합니다.
5. Outliner에서 원본 **Body**를 클릭하고 뷰포트 위에서 **H**를 누릅니다. 원본만 숨겨집니다.
6. Outliner에서 **Body_ArmsStudy**를 클릭합니다. 뷰포트에서 **View → Local View → Toggle Local View**를 선택합니다. 복사본만 보이면 됩니다.
7. **View → Viewpoint → Front**를 선택합니다. 왼쪽 위가 `Front Orthographic`인지 확인합니다. 원근이면 **View → Perspective/Orthographic**으로 바꿉니다.

## 2. 한쪽으로 양쪽을 만드는 설정

1. 복사본을 선택한 **Object Mode**에서 오른쪽 **Properties → Modifiers(렌치 아이콘)**를 클릭합니다.
2. **Add Modifier**를 누르고 검색에 `Mirror`를 입력해 **Mirror**를 선택합니다.
3. Mirror 설정을 아래처럼 맞춥니다. 이미 켜진 칸은 다시 눌러 끄지 않습니다.

| 칸 이름 | 값 |
|---|---|
| Axis | **X만 켜기**, Y·Z 끄기 |
| Bisect | **X만 켜기** |
| Flip | X·Y·Z 모두 끄기 |
| Mirror Object | 비워 두기 |
| Merge | 켜기, 거리 `0.0001` |
| Clipping | 켜기 |
| Bisect Distance | 보이면 `0.0001` |

4. 팔과 몸이 좌우 한 쌍으로 보이는지 확인합니다. **Modifier의 Apply는 누르지 않습니다.**
5. 위쪽 변환 방향 메뉴를 **Global**로 맞춥니다.

## 3. 한쪽 손만 선택하기

1. **Tab**을 눌러 Edit Mode로 들어갑니다.
2. 뷰포트 위쪽 선택 종류에서 **점 모양 Vertex Select**를 클릭합니다. 기본 키맵에서는 숫자패드가 아닌 윗줄 **1**입니다.
3. **Alt+A**로 선택을 모두 해제합니다.
4. 뷰포트 위쪽 **Options → Mirror**의 X·Y·Z와 **Topology Mirror**, **Auto Merge**가 꺼져 있는지 확인합니다. 같은 설정이 N → Tool → Options에 표시될 수도 있습니다. 위쪽 자석 모양 **Snap**도 끕니다. 이번에는 별도의 Mirror Modifier를 사용합니다.
5. 오른쪽 위 **X-Ray**를 켭니다. 단축키는 Alt+Z이며 이미 켜져 있으면 그대로 둡니다.
6. **B**를 누르고 **화면 오른쪽 손의 손목 바로 몸 쪽부터 손가락 끝까지** 사각형으로 드래그합니다. 손가락과 손바닥을 통째로 포함합니다. 몸통·반대 손은 선택하지 않습니다.
7. 오른쪽 손 전체의 점들이 선택 색으로 보이는지 확인합니다. 잘못 골랐으면 Alt+A 후 다시 B로 선택합니다. 원본의 반대쪽 점이 보이더라도 고르지 않습니다.

정면 보기에서 화면 오른쪽은 이 파일의 **X 양수 쪽**입니다. 캐릭터 자신의 오른팔이라는 뜻은 아닙니다. 선택은 여기 한쪽에서만 합니다.

## 4. 두 팔 함께 늘리기

1. 뷰포트 위쪽 **Proportional Editing** 원형 버튼을 켭니다. 그 옆 펼침 메뉴에서 **Projected from View를 먼저 끄고**, **Connected Only를 켠 뒤 Smooth**를 선택합니다.
2. 같은 펼침 메뉴의 **Proportional Size에 `0.12`**를 입력합니다.
3. 마우스를 뷰포트에 놓고 **G → X → 0.02 → Enter**를 누릅니다. `0.02`는 이 모델 크기에서 시작해 볼 **연습 이동량**입니다. 조정이 필요하면 바로 **F9**로 마지막 작업 설정을 엽니다.
4. 두 손이 같은 양만큼 바깥으로 이동하고, 손목 안쪽의 팔이 부드럽게 늘어났는지 확인합니다. **Mirror 설정 직후와 비교해 손가락 모양·몸통·어깨 중심은 그대로여야 합니다.**
5. 가슴이나 어깨까지 움직였으면 F9에서 Proportional Size를 줄입니다. 손가락이 길어졌으면 Ctrl+Z 후 손 전체를 선택했는지 확인합니다.
6. 충분하면 Proportional Editing과 X-Ray를 끄고 **Tab**으로 Object Mode로 돌아옵니다.

`0.02`는 ‘팔 길이 2% 증가’가 아닙니다. 더 늘리고 싶으면 F9의 X 이동량을 바꾸어 같은 작업을 조정합니다. G를 다시 반복하면 이동량이 누적됩니다.

## 5. 완료 확인과 저장

1. 정면·위·옆에서 손 크기, 팔의 꺾임, 어깨 변화, 중앙 이음선을 확인합니다.
2. **View → Local View → Toggle Local View**로 다른 물체를 다시 봅니다.
3. 소매·장갑·장식이 있는지 확인합니다. 별도 옷은 자동으로 늘어나지 않으므로 Body 수정과 구분합니다.
4. 원본 Body는 숨긴 상태, 복사본은 보이는 상태로 둡니다. Outliner에서 이름을 확인합니다.
5. **Ctrl+S**로 새 작업 파일에 저장합니다. Mirror는 적용하지 않고 남겨 둡니다.

완료: Body 복사본이 좌우 같은 모양이며, 한쪽 팔 수정이 반대쪽 결과에 계속 반영됩니다. 의상 맞춤·뼈 연결·Unity 확인은 이 작업의 완료 범위에 포함하지 않습니다.

| 문제가 생기면 | 바로 할 일 |
|---|---|
| 화면 왼쪽만 직접 움직이고 결과가 안 변함 | Ctrl+Z 후 X 양수인 화면 오른쪽 손을 선택 |
| 겹친 몸이 두 개 보임 | 원본 Body 숨김, Bisect X 켜짐 확인 |
| 한쪽만 변함 | Mirror의 X와 뷰포트 표시 아이콘 확인 |
| 손 일부가 늘어나 찌그러짐 | X-Ray를 켜고 손 전체를 다시 선택 |
| 몸통까지 늘어남 | Proportional Size 축소, 선택에 몸통이 섞였는지 확인 |
| 수정 범위를 모르겠음 | 즉시 Ctrl+Z, 원본을 복제한 단계로 돌아가기 |
