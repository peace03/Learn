# 10. 규칙으로 모양을 만드는 Geometry Nodes

먼저: [메시](03_%EB%A9%94%EC%8B%9C%EC%99%80_%EB%AA%A8%EB%8D%B8%EB%A7%81.md), [노드 기초](06_%EC%9E%AC%EC%A7%88%EA%B3%BC_%EB%85%B8%EB%93%9C.md).

같은 단추를 옷 위에 많이 놓을 때 매번 손으로 복사하면 수정도 반복해야 합니다. [Geometry Nodes](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#geometry-nodes)는 **입력 형상 → 규칙 → 출력 형상**을 만들어 규칙을 바꾸면 결과도 다시 계산하게 합니다. 이번 부츠 한 번 [반전](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)에는 필요하지 않지만 반복 제작에 쓰입니다.

## 형상 흐름과 요소별 계산

형상은 [메시](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)·[커브](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#curve)·점 무리·[인스턴스](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#instance) 같은 구성 요소를 담을 수 있습니다. 각 요소에 붙는 자료가 [Attribute](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#attribute)이고, [정점](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#vertex)인지 면인지처럼 어디에 붙는지를 [Domain](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#domain)이라고 합니다.

[상수](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#constant) 0.1은 모든 곳에 같은 수를 줍니다. [Field](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#field)는 ‘각 점의 위치를 읽어 높이를 구하라’처럼 나중에 요소별로 실행할 규칙입니다. 같은 필드도 어느 형상·어느 도메인에서 계산하느냐에 따라 값이 달라집니다. [공식 Fields](https://docs.blender.org/manual/en/latest/modeling/geometry_nodes/fields.html).

```text
형상 입력 → 각 점의 현재 위치 확인 → 조건에 맞는 점만 변경 → 형상 출력
                    ↑
            요소별 계산 규칙(Field)
```

첫 변경 뒤에 [Position](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#position-field)을 다시 읽으면 바뀐 위치를 읽을 수 있습니다. 변경 전 값을 계속 써야 하면 특정 단계에서 [Capture Attribute](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#capture-attribute)로 저장하는 이유가 생깁니다. [Named Attribute](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#named-attribute)는 이름으로 찾고, [Anonymous Attribute](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#anonymous-attribute)는 연결 관계로 전달하는 자료입니다.

## 복사와 참조는 다르다

Instance는 원본을 참조하며 각자의 배치 정보를 갖습니다. 나무 천 그루를 매번 완전한 메시로 복사하는 것보다 효율적으로 다룰 수 있습니다. 하지만 각 정점을 직접 다뤄야 하는 계산에서는 [Realize Instances](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#realize)로 실제 형상으로 바꿔야 할 수 있고, 그때 처리량이 커집니다.

[Index](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#index)는 현재 순번이라 추가·삭제 뒤 바뀔 수 있습니다. [ID](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#id)는 대상 식별에 쓰는 값입니다. 무작위 배치를 안정적으로 유지하려면 어떤 값을 기준으로 삼는지와 [Seed](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#seed)를 함께 봅니다.

## 반복과 시간은 다르다

[Repeat Zone](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#repeat-zone)은 한 결과를 만들기 위해 같은 처리를 여러 번 합니다. [Simulation Zone](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#simulation-zone)은 이전 시간의 상태를 다음 시간으로 전달합니다. 길을 열 번 세분하는 계산과 공이 10[프레임](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#frame) 동안 움직이는 계산은 다릅니다.

어디서 확인하나: [Geometry](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#geometry) [Node](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node) [Editor](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#editor)는 규칙 연결, [Spreadsheet](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#spreadsheet)는 실제 요소별 값, [Modifier](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier) 입력은 사용자가 조절할 값, [뷰포트](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport)는 최종 모양을 봅니다. 노드 그림이 깔끔하다는 것만으로 값이 올바른지는 알 수 없습니다.

확인 질문: **같은 Position 연결을 두 번 쓰면 항상 같은 위치인가?** 답: 평가 지점의 형상이 달라졌다면 다른 값일 수 있습니다. 원래 값을 쓸지 현재 값을 쓸지 구분합니다.
