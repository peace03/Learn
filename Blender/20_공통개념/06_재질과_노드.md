# 06. 재질은 빛에 반응하는 규칙

먼저: [UV와 텍스처](05_UV와_텍스처.md).

모양은 같아도 고무·금속·가죽은 다르게 보입니다. [재질](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)은 ‘빨간색’ 하나가 아니라 **어떤 빛을 어느 방향으로 보내고 얼마나 통과시키는가**를 정합니다. [셰이더](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader)는 이 반응을 계산하는 규칙입니다.

## 빛은 어떻게 나뉘나

들어온 빛 일부는 돌아가고, 일부는 안으로 들어가며, 일부는 [흡수](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#absorption)됩니다. 표면 방향과 보는 방향도 결과에 관계됩니다. [BSDF](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#bsdf)는 이런 방향별 반응을 표현하는 말입니다. [PBR](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pbr)은 이 성질을 물리 원리에 맞춰 다루려는 접근입니다.

| 조절값 | 쉽게 생각하기 | 혼동하지 않을 것 |
|---|---|---|
| [Base Color](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#base-color) | 재질의 기본 색 성질 | 최종 화면 색과 항상 같지 않음 |
| [Roughness](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#roughness) | 작은 거울 조각들이 향한 방향의 흩어짐 | 실제 표면 점을 울퉁불퉁하게 만들지 않음 |
| [Metallic](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#metallic) | 금속 계열의 빛 반응 | 무조건 올리면 고급스러워지는 값이 아님 |
| [IOR](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#ior) | 경계에서 빛이 꺾이고 반사되는 성질 | 단순 투명도 값과 다름 |
| [Transmission](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#transmission) | 재질 내부를 통과하는 빛 | [알파](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#alpha)로 그림을 지우는 것과 다름 |
| [Emission](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#emission) | 스스로 내는 빛 | 주변 조명 효과는 엔진·설정 확인 |

[Principled BSDF](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#principled)는 여러 성질을 한 [노드](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)에서 다루게 합니다. 피부의 내부 [산란](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#scattering)은 [SSS](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#sss), 코팅은 [Coat](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#coat), 섬유의 부드러운 반사는 [Sheen](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#sheen) 등으로 나누어 생각합니다. 마찰로 생긴 홈의 방향에 따라 반사가 늘어지는 성질은 [Anisotropy](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#anisotropy)입니다.

## 노드는 계산 순서다

[Shader Editor](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader-editor)에서 노드는 계산 블록, [Socket](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#socket)은 입력·출력 구멍, 연결선은 값의 전달입니다.

```text
이미지의 색 → 표면 셰이더의 Base Color
거칠기 값  → 표면 셰이더의 Roughness
표면 셰이더 → 재질 최종 표면 출력
```

표면 출력에 도달하지 않는 계산은 결과에 쓰이지 않을 수 있습니다. 결과가 이상하면 최종 출력에서 입력을 거슬러 올라가며 값·연결·읽는 이미지를 확인합니다. 같은 노드 이름처럼 보여도 번역이나 사용자의 이름 변경이 가능하므로 기능과 연결을 함께 봅니다.

[노드 그룹](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node-group)은 여러 계산을 재사용하도록 묶습니다. [절차적](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#procedural) [텍스처](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)는 이미지 대신 위치와 수학 규칙으로 무늬를 만들 수 있습니다. 다른 프로그램에 같은 규칙이 없으면 겉모양을 옮기기 위해 [베이크](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#bake)나 재질 재구성이 필요합니다.

## 어디에서 확인하나

[Shading](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shading) 작업 탭의 Shader Editor에서 **현재 편집 대상이 [Object](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)의 Material인지 [World](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#world-shader)인지** 확인합니다. [Outliner](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner)에서 새 부츠를 [선택](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)했다고 자동으로 공유 재질이 독립되는 것은 아닙니다. 재질 사용자 수도 읽습니다.

확인 질문: **[Blender](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender)의 재질을 [FBX](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#fbx)로 보내면 [Unity](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#unity)에서 완전히 같은가?** 답: 아닙니다. 지원되는 자료만 전달되며 빛 계산·노드·색 관리도 다를 수 있습니다. 같은 텍스처를 받아 목적 엔진의 재질로 맞추고 화면에서 검사해야 합니다.
