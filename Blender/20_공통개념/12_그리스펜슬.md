# 12. 3D 공간에서 그리는 2D 그림

먼저: [좌표](02_좌표와_대칭.md), [키프레임](09_리깅과_애니메이션.md).

[Grease Pencil](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#grease-pencil)은 선과 [채움](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#fill)으로 그림을 만들고 움직이는 체계입니다. 일반 페인트 이미지처럼 색칸만 저장하는 방식과 달리 선을 이루는 점·두께·[재질](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 정보를 다룰 수 있습니다. [장면](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene) 안에 있으므로 [카메라](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)와 공간 배치도 관계됩니다.

## 한 줄에서 장면까지

[Stroke](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#stroke)는 한 번 이어 그린 선입니다. 여러 선을 Layer로 나눠 배경·몸·표정 등을 관리할 수 있습니다. 현재 활성 Layer에 그려지므로 다른 층에 그리는 실수를 주의합니다. 불투명도와 [마스크](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#mask)는 어떤 그림이 얼마나 보일지를 정합니다. [공식 Grease Pencil Layers](https://docs.blender.org/manual/en/latest/grease_pencil/properties/layers.html).

선의 앞뒤와 실제 공간 깊이를 구분해야 합니다. 2D 레이어 순서와 3D 카메라 관계가 함께 결과에 영향을 줄 수 있습니다. 그림이 가려지면 색을 다시 칠하기 전에 배치·레이어·표시 조건을 확인합니다.

## 시간별 그림과 물체 이동

그림 [애니메이션](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#animation)은 [프레임](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#frame)마다 다른 그림을 만들 수 있습니다. 또는 같은 그림 물체를 이동·[회전](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)시킬 수도 있습니다. 전자는 그림 자체의 변화, 후자는 배치 변화입니다. [Onion Skin](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#onion-skin)은 앞뒤 프레임 그림을 겹쳐 보여 줘 움직임 간격을 비교하게 합니다.

그림을 일정 간격으로 조금씩 옮기면 일정한 움직임처럼 보이고, 간격을 넓히면 빨라지는 인상을 줍니다. [키프레임](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#keyframe) [보간](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#interpolation)과 사람이 직접 그린 중간 그림의 차이를 이해하면 두 방식을 섞기 쉽습니다.

| 만들 목적 | 관련 자료·도구 | 주의 |
|---|---|---|
| 손그림 캐릭터 | Stroke·Fill·Layer | 틈이 있으면 채움이 새거나 끊길 수 있음 |
| 움직임 확인 | 시간별 그림·Onion Skin | 이전 그림의 보조 표시를 최종 그림과 혼동하지 않음 |
| 입체 배경과 함께 쓰기 | Camera·3D 위치·재질 | [좌표](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)와 조명 조건 확인 |
| 부위별 제어 | 레이어·마스크·지원 [모디파이어](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier) | 일반 [메시](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 도구와 동일하지 않음 |

Grease Pencil은 버전 변화가 큰 분야입니다. 예전 튜토리얼의 메뉴·[데이터](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data) 구조를 현재 버전과 바로 같다고 생각하지 않습니다. 이 자료는 개념을 정리하며, 특정 그림 제작 목적이 생길 때 현재 [UI](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#ui)로 클릭 실습을 추가합니다.

확인 질문: **그림 한 장을 3D 공간에 놓으면 왜 [평면](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#plane)처럼 보일 수 있는가?** 답: 그림의 점들이 한 평면에 놓여 있다면 [시점](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)이 바뀌어도 입체 부피가 저절로 생기지 않기 때문입니다.
