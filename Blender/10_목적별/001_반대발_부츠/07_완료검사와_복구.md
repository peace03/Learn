# 07. 완료 검사와 복구

현재 목적은 **반대 발에 맞춘 별도 부츠의 정적 배치**입니다. 아래를 직접 확인한 뒤 완료로 기록합니다. 문서 작성자가 대신 [반전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)·저장을 실행한 상태는 아닙니다.

## 완료 체크

- [ ] [Outliner](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner)에 원본 `Boots1-1`과 새 `Boots_Opposite`가 각각 있다.
- [ ] 원본의 위치·모양·이름이 그대로다.
- [ ] 새 부츠가 반대 X 쪽에 있고 발끝이 같은 전방을 향한다.
- [ ] 정면·옆면·위·비스듬한 근접 보기에서 높이와 [관통](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#intersect)을 확인했다.
- [ ] [Apply Scale](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply-scale)을 했다면 새 부츠 [Scale](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#scale)은 (1,1,1)이고 겉모양은 유지된다.
- [ ] 면 방향과 그림을 확인했다. 열린 입구의 뒷면과 오류를 구분했다.
- [ ] [Transform Pivot Point](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)는 [Median Point](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#median)로 되돌렸다.
- [ ] 현재 파일이 새 작업 이름인지 확인하고 File → Save 또는 Ctrl+S로 저장했다.
- [ ] 현재는 발 뼈가 없어 [애니메이션](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#animation) 연결은 완료하지 않았다고 기록했다.

## 증상으로 찾는 복구

| 증상 | 먼저 확인 | 복구 방향 |
|---|---|---|
| 반대 발로 안 옮겨짐 | 피벗 위치 | 반전 취소 후 원점 커서·[Global](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global)·[3D Cursor](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#cursor) 설정 |
| 머리 쪽으로 부츠가 뒤집혀 올라감 | Z 반전 여부 | 취소 후 X 반전 |
| 발끝이 뒤로 향함 | Z 180도 [회전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation) 여부 | 회전 취소 후 거울 반전 |
| 원본도 바뀜 | [선택](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection) 수, [메시](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)·[재질](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 공유 | 즉시 [Undo](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#undo) 후 선택·사용자 수 확인 |
| 크기 조절할 때 자리가 멀리 움직임 | 커서 피벗이 남았는지 | Median Point로 변경 |
| [적용](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply) 후 검거나 안쪽이 보임 | 면 방향·조명·재질 | 원본과 비교. 필요할 때만 [법선](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#normal) 복구 |
| [텍스처](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)가 분홍색 등으로 보임 | 외부 이미지 경로 | 원본 이미지 위치 확인. 반전을 다시 하는 문제가 아님 |
| 부츠를 움직였는데 발은 안 따라옴 | 배치와 뼈 연결 혼동 | 현재는 정적 배치. 실제 [리그](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#rig)가 필요 |
| 발 뼈를 돌려도 새 부츠가 안 움직임 | [부모](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#parent) 또는 [Armature](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#armature)·그룹·[가중치](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#weight) | 어떤 연결 방식인지부터 확인 |

잘못된 명령 직후라면 Ctrl+Z가 가장 짧은 복구입니다. 여러 단계를 진행했다면 하나씩 취소하며 이름·위치를 확인합니다. 어느 상태인지 모르겠으면 새 작업 파일을 보존한 뒤 원본 파일과 비교합니다. 열려 있는 저장 전 작업을 무심코 다시 불러오지 않습니다.

## 결과 기록 예시

```text
파일: 내가 저장한 새 작업 파일 경로
완료: 반대편 부츠 배치 / 스케일 검사 / 면 방향 검사
확인한 시점: 정면, 옆면, 위, 발목 근접
남은 일: 실제 발·종아리 리그에 변형 연결 후 동작 검사
Unity 확인: 아직 안 함
```

[내보내기](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#export) 파일이 생겼다는 사실과 Unity에서 크기·재질·애니메이션이 정상이라는 사실은 별도로 확인해야 합니다.
