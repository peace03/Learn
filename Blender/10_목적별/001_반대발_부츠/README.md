# 001. 기존 부츠를 반대 발에 맞추기

**결과물:** 원래 `Boots1-1`을 남겨 두고, X 반대편에 `Boots_Opposite`라는 별도 부츠를 만들어 발에 맞춘 작업 파일.

이름으로 좌우를 단정하지 않습니다. 화면에서 왼쪽인 것과 캐릭터의 왼발은 [시점](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)에 따라 다릅니다. 현재 확인한 원본은 **전역 X가 음수인 쪽**, 새 부츠는 **X가 양수인 쪽**입니다.
