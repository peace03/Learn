# 04. 반대 발에 맞추기

[거울 반전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)은 수학적으로 정확해도 몸이 좌우 [대칭](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#symmetry)이 아니면 꼭 맞지 않을 수 있습니다. 목표는 **밑창 높이·발끝 방향·발목·종아리 공간**을 여러 방향에서 확인하는 것입니다. 현재 단계는 겹쳐 배치하는 작업이며 아직 뼈 연결이 아닙니다.

## 검사하고 필요한 만큼만 조정하기

1. 새 부츠 `Boots_Opposite` 하나를 [선택](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)합니다. [Object Mode](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode), [Global](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global), [Median Point](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#median)를 확인합니다.
2. [View](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view) → [Viewpoint](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#viewpoint) → **[Front](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#front)**로 갑니다. 원래 부츠와 새 부츠의 밑창 높이·긴 부분의 높이를 비교합니다.
3. **[Right](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#right-view)**로 바꿔 발뒤꿈치와 발끝 방향을 봅니다. 옆면에서는 두 다리가 겹쳐 보일 수 있으므로 시점을 조금 돌려 확인합니다.
4. **[Top](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#top-view)**으로 바꿔 양발의 앞뒤 위치와 벌어진 [각도](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#angle)를 봅니다.
5. 휠로 발목에 접근하고 가운데 버튼 드래그로 둘러봅니다. 몸 표면이 부츠 밖으로 뚫고 나오는지 확인합니다.
6. 필요한 축만 조금 이동합니다. 예를 들어 `G → X → 0.002 → Enter`는 현재 [장면](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene) 단위에서 +X로 0.002만큼 이동합니다. 이 수는 **입력 예시**이며 현재 모델에 반드시 맞는 보정값이 아닙니다.
7. 잘못 움직였으면 즉시 Ctrl+Z합니다. 한 번에 위치·각도·크기를 모두 바꾸지 말고 한 항목씩 확인합니다.

마우스로 조절하려면 [Toolbar](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#toolbar)에서 **[Move](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#translation)**를 클릭하고 필요한 축 화살표만 드래그합니다. 수치가 필요한 경우 N → [Item](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item)에서 입력합니다. 몸과 부츠가 모두 선택되어 있으면 몸도 움직이므로 목록을 확인합니다.

## 크기와 회전은 이유가 있을 때만

- 전체가 작으면 S로 균일하게 키웁니다. 각 축을 다르게 키우면 장식과 원형 부분도 찌그러집니다.
- 발끝 방향만 다르면 R → 필요한 축 → 작은 각도로 조정합니다. Global Z [회전](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)은 위에서 보는 방향을 바꿀 때 쓰지만, 경사진 발은 다른 축도 관계됩니다.
- 한 부위만 맞지 않으면 전체 크기 변경으로 해결하지 못할 수 있습니다. 그때는 [메시](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 편집·[비례 편집](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#proportional)·[리토폴로지](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#retopology) 같은 별도 판단이 필요합니다. 이번 예시에서는 임의로 몸이나 장식을 재구성하지 않습니다.

S를 누를 때 부츠가 멀리 이동하면 [피벗](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)이 [3D Cursor](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#cursor)인지 먼저 확인합니다. 부츠의 Z를 0으로 맞추는 것은 ‘땅에 놓기’가 아닙니다. 현재 몸의 원점은 발바닥과 다르고, 정상 부츠도 Z가 음수입니다.

## 겉보기와 실제 완료의 차이

| 보기 | 확인할 부분 |
|---|---|
| 정면 | 좌우 간격, 밑창 높이, 몸 밖으로 튀어나온 부분 |
| 옆면 | 발끝 방향, 발뒤꿈치, 밑창 앞뒤 길이 |
| 위 | 발의 벌어짐, 좌우 부츠가 서로 겹치는지 |
| 비스듬한 근접 보기 | 종아리·발목 [관통](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#intersect), 내부와 외부 경계 |

정지 자세에서 잘 맞는다고 걸을 때도 잘 맞는 것은 아닙니다. 실제 발 뼈가 생긴 뒤 발목을 굽혀 검사해야 합니다. 이 단계에서는 원본 부츠가 변하지 않았고 반대편 새 부츠의 정적인 위치가 맞는지까지 확인합니다.
