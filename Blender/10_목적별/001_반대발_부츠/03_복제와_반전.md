# 03. 복제하고 반대편으로 뒤집기

시작 조건: 새 작업 파일, [Object Mode](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode), 원본 `Boots1-1` 하나 [선택](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection). 이 단계는 **물체 전체의 [변환](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)**으로 진행합니다.

## 1. 독립된 복사본 만들기

1. [Outliner](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner)에서 `Boots1-1`만 클릭합니다. 마우스를 [3D Viewport](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport)로 옮깁니다.
2. **[Shift+D](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#duplicate)**를 누릅니다. 복사본이 생기고 자동으로 마우스를 따라 움직이는 상태가 됩니다.
3. **오른쪽 클릭 한 번 또는 Esc**로 방금 시작된 이동만 취소합니다. 복사본은 원본과 같은 자리에 남습니다.
4. **F2**를 누르고 `Boots_Opposite`를 입력한 뒤 Enter를 누릅니다.
5. Outliner에 원본과 새 이름이 각각 존재하는지 확인합니다. 새 부츠만 선택된 상태를 유지합니다.

메뉴로는 **[Object](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object) → Duplicate Objects**입니다. 기본 Shift+D는 별도 [메시](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)를 만들지만 [재질](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)은 공유할 수 있습니다. [Alt+D](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#linked-duplicate)는 메시까지 연결하는 복제이므로 이번 작업과 구분합니다. [공식 Duplicate 설명](https://docs.blender.org/manual/id/5.2/scene_layout/object/editing/duplicate.html).

중요: 이동 취소는 복제 취소가 아닙니다. 실수로 두 번 복제했다면 Outliner의 새 이름들을 확인하고 불필요한 복사본만 선택해 X → Delete로 지웁니다. 원본 이름을 지우지 않습니다.

## 2. 전역 방향과 몸 중심을 정하기

1. 뷰포트 위쪽 **[Transform Orientation](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#orientation)** [드롭다운](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#dropdown)에서 **[Global](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global)**을 선택합니다. 보통 Global 또는 [Local](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#local)이라는 글자가 표시된 칸입니다.
2. 마우스를 뷰포트 안에 놓고 **Shift+S → [Cursor to World Origin](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#cursor-to-origin)**을 클릭합니다.
3. N → **[View](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view) → [3D Cursor](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#cursor)**에서 [Location](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#location) X/Y/Z가 모두 0인지 확인합니다. [Item](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item)의 부츠 Location을 0으로 바꾸는 것이 아닙니다.
4. 위쪽 **[Transform Pivot Point](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)** 드롭다운을 클릭해 **3D Cursor**를 선택합니다. 이름을 모르겠으면 아이콘 위에 마우스를 잠시 올려 설명을 읽습니다.

3D Cursor 이동은 작업 기준만 바꿉니다. **[Selection to Cursor](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection-to-cursor)**를 고르면 부츠 자체가 커서로 이동하므로 다른 명령입니다. 잘못 골랐다면 Ctrl+Z 후 Cursor to World Origin을 선택합니다. [공식 Snap 설명](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/snap.html).

## 3. X 방향 거울 반전

1. 새 부츠만 선택되어 있고, Object Mode·Global·3D Cursor 피벗인지 다시 읽습니다.
2. **Ctrl+M → X → Enter**를 누릅니다. X는 한 번만 누릅니다. 축 키를 반복하면 [좌표](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate) 방향 기준이 바뀔 수 있습니다.
3. 메뉴로 하려면 **Object → [Mirror](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection) → X Global**을 선택합니다.
4. 반전 직후 새 부츠가 X 양수 쪽으로 이동했는지 정면에서 확인합니다.
5. N → Item → Transform에서 새 부츠의 Location을 확인합니다. 다른 맞춤 작업을 하지 않았다면 약 **X +0.078414, Y -0.022287, Z -0.346911**이 예상됩니다.

이는 원점·전역 기준에서 `S → X → -1 → Enter`와 같은 거울 효과를 냅니다. 둘을 연달아 실행하면 원래 방향으로 돌아오므로 **한 방법만** 실행합니다. 원본의 X는 음수로 남아야 합니다.

## 4. 작업 기준을 되돌리기

반전이 끝나면 **Transform Pivot Point → [Median Point](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#median)**를 선택합니다. 커서를 피벗으로 남겨 두면 이후 크기 조절에서 부츠가 몸 중심을 향해 움직일 수 있습니다. Global은 유지합니다.

| 이상한 결과 | 확인할 것 | 복구 |
|---|---|---|
| 제자리에서 모양만 뒤집힘 | 피벗이 부츠 [Origin](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#origin)인지 | Ctrl+Z → 커서 원점·피벗 재설정 |
| 위아래가 뒤집힘 | Z를 눌렀는지 | Ctrl+Z → X로 한 번 반전 |
| 원본도 함께 움직임 | 두 물체를 선택했는지 | Ctrl+Z → 새 부츠 하나 선택 |
| 몸 중심에서 비스듬히 뒤집힘 | Local 또는 기울어진 기준인지 | Ctrl+Z → Global 확인 |
| 복사본이 안 보임 | 원본과 겹쳐 있는지 | Outliner에서 새 이름을 선택해 위치 확인 |

실제 [데이터](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data) 반전 명령과 [모디파이어](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier)는 구별합니다. [Mirror Modifier](../../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#mirror-modifier)는 기본적으로 로컬 축·오리진을 사용합니다. 지금 피벗만 바꾸고 모디파이어를 추가하면 같은 결과를 보장하지 않습니다. [공식 Object Mirror](https://docs.blender.org/manual/en/4.5/scene_layout/object/editing/mirror.html), [Mirror Modifier](https://docs.blender.org/manual/en/5.0/modeling/modifiers/generate/mirror.html).
