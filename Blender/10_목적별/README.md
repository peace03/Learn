# 목적별 사용 설명서

실제로 해야 할 일이 생길 때 한 항목씩 추가합니다. 현재 문서화한 목적은 아래 한 가지입니다.

| 번호 | 목적 | 시작 자료 | 완료 기준 |
|---|---|---|---|
| 001 | [기존 부츠를 반대 발에 맞추기](001_반대발_부츠/README.md) | 한쪽 부츠와 몸체 | 원본을 보존한 반대편 부츠, 표면·간섭 검사, 새 파일 저장 |

발 뼈가 없는 현재 [장면](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)에서는 정적인 배치까지 실습합니다. ‘캐릭터가 걸을 때 장화가 함께 휘기’는 해당 [뼈대](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#armature)가 준비된 뒤 같은 목적의 연결 단계를 보완하거나 별도 목적 문서로 추가합니다.

새 목적이 생기면 [추가 양식](../99_관리/목적추가_양식.md)을 사용합니다. 새 문서만 만들고 사전을 비워 두지 않습니다. 처음 등장하는 전문 용어를 사전에 추가하고 필요한 기초 개념까지 연[결합](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#join)니다.
