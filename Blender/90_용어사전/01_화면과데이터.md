## Blender / 블렌더

**뜻:** 입체 모양, 그림, 움직임, 영상을 만드는 프로그램.

**원리·용도:** 모양을 저장하는 [데이터](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)와 그 데이터를 보여 주는 화면은 다르다. 화면을 돌려도 물체 자체가 [회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)한 것은 아니다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="ui"></a>

## UI / 사용자 인터페이스

**뜻:** 사람이 프로그램에 명령을 주는 버튼·창·메뉴의 묶음.

**원리·용도:** 같은 단축키도 마우스가 어느 창에 있는지에 따라 다른 일을 한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="editor"></a>

## Editor / 에디터

**뜻:** 특정 종류의 자료를 다루는 작업 창.

**원리·용도:** [3D Viewport](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport)는 모양을, [Shader Editor](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#shader-editor)는 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 계산을 다룬다. 화면 구역마다 종류를 바꿀 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="viewport"></a>

## 3D Viewport / 뷰포트

**뜻:** 물체를 보면서 [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)하고 편집하는 입체 작업 창.

**원리·용도:** 작업용 [시점](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)은 렌더에 쓰는 [카메라](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)와 별개다. 화면 탐색은 결과물 [좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)를 바꾸지 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="workspace"></a>

## Workspace / 워크스페이스

**뜻:** 작업에 맞게 여러 [에디터](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#editor)를 배치한 화면 구성.

**원리·용도:** [Layout](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#layout), [Modeling](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#modeling), [Shading](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shading) 등은 작업 창 배치다. 다른 탭으로 가도 같은 [데이터](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)가 보일 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="layout"></a>

## Layout / 레이아웃

**뜻:** 창과 도구가 놓인 배치. Layout은 기본 작업 탭 이름이기도 하다.

**원리·용도:** 창 경계를 드래그하면 구역 크기가 변한다. 모델 크기는 변하지 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="outliner"></a>

## Outliner / 아웃라이너

**뜻:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene) 속 물체와 묶음을 이름으로 보여 주는 목록 창.

**원리·용도:** 겹친 물체를 화면에서 찍기 어려우면 여기서 정확한 이름을 [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="properties"></a>

## Properties / 프로퍼티 에디터

**뜻:** 렌더, 물체, [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 등 설정을 주제별 탭으로 보여 주는 창.

**원리·용도:** [3D Viewport](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport) 안의 N [사이드바](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#sidebar)와 별개다. [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)된 대상에 따라 보이는 탭이 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## Sidebar / 사이드바

## Object Mode / 오브젝트 모드

**뜻:** 물체를 통째로 [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)하고 배치하는 상태.

## Edit Mode / 편집 모드

[Object Mode](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode) [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)과 저장 위치가 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## Single User / 싱글 유저

## Duplicate / Duplicate Objects / 복제 / Shift+D

**원리·용도:** 배치는 따로 바꾸지만 한쪽 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 편집은 양쪽에 반영된다. 좌우 부츠를 독립 수정하려면 주의한다.
