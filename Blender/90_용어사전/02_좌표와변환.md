<a id="dimension"></a>

## Dimension / 차원

**뜻:** 위치를 표시하는 데 필요한 독립 방향의 수.

**원리·용도:** 2D는 두 방향, 3D는 세 방향이 필요하다. 화면은 2D여도 계산 중인 모양은 3D일 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="coordinate"></a>

## Coordinate / 좌표

**뜻:** 기준점에서 각 방향으로 얼마나 떨어졌는지 나타낸 수.

**원리·용도:** (2,0,1)은 X로 2, Y로 0, Z로 1만큼 떨어진 점이다. 기준 공간을 함께 알아야 뜻이 정해진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="axis"></a>

## Axis / 축

**뜻:** 위치·이동·[회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation) 방향을 구분하는 기준선.

**원리·용도:** [Blender](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender) 기본 공간에서 Z는 위아래다. 모형이 누워 있으면 물체의 좌우와 세계 X는 다를 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="global"></a>

## Global / World Space / 전역 좌표 / 월드 공간

**뜻:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene) 전체에 공통인 방향과 위치 기준.

**원리·용도:** 현재 부츠의 좌우 [반전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)은 Global X 방향으로 한다. 물체가 돌아 있어도 이 기준은 그대로다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="local"></a>

## Local / Local Space / 지역 좌표 / 로컬 공간

**뜻:** 각 물체 자체에 붙어 있는 방향과 위치 기준.

**원리·용도:** 물체가 [회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)하면 로컬 축도 함께 돌아간다. 현재 부츠의 Local X는 [Global](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global) X와 조금 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="origin"></a>

## Origin / 오리진

**뜻:** 물체 [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)의 기준이 되는 물체 자체의 점.

**원리·용도:** 물체의 표면 중심과 항상 같지 않다. 오리진 이동과 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 이동을 혼동하면 [반전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection) 위치가 틀어진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="world-origin"></a>

## World Origin / 월드 원점

**뜻:** [전역 좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#global)가 (0,0,0)인 점.

**원리·용도:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)의 수학적 기준일 뿐 항상 발바닥 높이는 아니다. 현재 부츠는 Z가 음수여도 정상 위치다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="cursor"></a>

## 3D Cursor / 3D 커서

**뜻:** 사용자가 놓을 수 있는 임시 위치·방향 기준.

**원리·용도:** 새 물체를 놓거나 [피벗](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)으로 쓴다. 마우스 화살표와 다르며 물체를 [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)했다고 자동으로 이동하지 않는다.

<a id="pivot"></a>

## Pivot Point / Transform Pivot Point / 피벗

**뜻:** 현재 [회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)·크기 변경 등에서 중심으로 삼는 점.

**원리·용도:** 같은 -1배 [반전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)도 피벗이 부츠 중심인지 몸 중심인지에 따라 위치가 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="median"></a>

## Median Point / 중앙값 피벗

**뜻:** [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection) 대상의 위치들을 평균 내어 만든 [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform) 기준.

**원리·용도:** 통계에서 가운데 순위 값을 뜻하는 중위수와 혼동하지 않는다. 물체 하나라면 보통 그 [오리진](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#origin)이 기준이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## Individual Origins / 개별 오리진

**뜻:** 여러 물체를 각자의 기준점 주변에서 [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)하는 [피벗](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot) 설정.

**원리·용도:** 양쪽 부츠를 각각 키울 때 둘 사이 간격까지 함께 늘리지 않으려는 용도로 쓴다.

## Active Element / 활성 요소 피벗

## Transform / 변환

**원리·용도:** [Object Mode](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode)에서는 물체 변환 값을, [Edit Mode](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#edit-mode)에서는 주로 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 점을 바꾼다.

## Rotation / Rotate / 회전

**뜻:** 기준을 중심으로 방향을 바꾸는 [변환](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform).

**원리·용도:** Z축 180도 회전은 X와 Y 방향을 모두 뒤집는다. 한 방향만 뒤집는 [거울 반전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)과 다르다.

**원리·용도:** X 반전은 YZ [평면](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#plane)을 기준으로 X [좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)를 뒤집는다. [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)의 [빛 반사](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#reflection-light)와는 [문맥](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#context)이 다르다.

<a id="snap"></a>

## Snap / 스냅

**뜻:** 이동 대상이나 커서를 특정 점·면·격자에 맞추는 기능.

**원리·용도:** 커서를 원점으로 보내기와 물체를 커서로 보내기는 다른 명령이다. 이름을 끝까지 읽는다.
