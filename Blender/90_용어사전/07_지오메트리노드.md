<a id="geometry-nodes"></a>

## Geometry Nodes / 지오메트리 노드

**뜻:** [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node) 계산으로 모양과 배치를 만드는 시스템.

**원리·용도:** 반복 구조·식물·[절차적](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#procedural) 변형에 쓴다. [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 노드는 빛 반응, 이 노드는 주로 형상을 다룬다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="attribute"></a>

## Attribute / 어트리뷰트 / 속성 자료

**뜻:** 점·면 등 각 요소에 붙여 저장한 값.

**원리·용도:** 위치, 색, 이름 붙인 [가중치](06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#weight) 등이 있다. 어느 요소에 붙었는지 알아야 올바르게 읽는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="domain"></a>

## Domain / 도메인

**뜻:** 속성이 붙거나 계산되는 요소의 종류.

**원리·용도:** [정점](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#vertex)마다 값 하나인지, 면마다 값 하나인지 정한다. [유체](08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#fluid)의 Domain은 계산 공간이라는 별도 뜻이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="field"></a>

## Field / 필드

**뜻:** 각 요소를 대상으로 나중에 계산할 규칙.

**원리·용도:** [Position](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#position-field)에 따른 높이 계산을 점마다 실행할 수 있다. 연결한 위치의 형상과 [도메인](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#domain)에 따라 값이 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="constant"></a>

## Constant / 상수

**뜻:** 정해진 계산 범위에서 변하지 않는 값.

**원리·용도:** 모든 점을 0.1만큼 올리는 값은 한 수다. 점마다 다른 높이를 만드는 [필드](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#field)와 구별한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="instance"></a>

## Instance / 인스턴스

**뜻:** 원본을 참조하면서 각자의 배치 등만 가진 표현.

**원리·용도:** 같은 나무를 많이 놓을 때 실제 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh) 복사보다 가볍게 다룰 수 있다. 편집 가능한 요소 종류에는 차이가 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="realize"></a>

## Realize Instances / 인스턴스 실체화

**뜻:** 참조 형태의 [인스턴스](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#instance)를 실제 형상으로 바꾸는 계산.

**원리·용도:** 점별 편집이 필요할 때 쓴다. 반복 수가 크면 메모리가 크게 늘어날 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="index"></a>

## Index / 인덱스

**뜻:** 현재 요소 배열에서의 순서 번호.

**원리·용도:** 요소 추가·삭제·순서 변경 후 달라질 수 있다. 영구 고유 번호라고 가정하면 안 된다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="position-field"></a>

## Position / 위치 필드

**뜻:** 평가 대상 형상 요소의 현재 위치를 읽는 [Geometry Nodes](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#geometry-nodes) 입력.

**원리·용도:** [Object](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)의 [Location](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#location)과 구별한다. 형상을 바꾼 다음 읽으면 바뀐 점 위치를 읽을 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="id"></a>

## ID / 식별자

**뜻:** 대상을 구분하기 위해 사용하는 값.

**원리·용도:** 안정적인 무작위 배치나 요소 [추적](09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#tracking)에 사용한다. [Index](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#index)와 역할이 같다고 단정하지 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="seed"></a>

## Seed / 시드

**뜻:** 무작위 계산의 출발 상태를 정하는 값.

**원리·용도:** 같은 조건과 시드면 같은 무늬를 다시 만들기 쉽다. 시드를 바꾸면 배치가 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="capture-attribute"></a>

## Capture Attribute / 속성 캡처

**뜻:** 특정 단계에서 계산한 값을 형상에 붙여 이후에도 쓰는 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node).

**원리·용도:** 변형 전 위치를 저장하면 변형 후 위치와 혼동하지 않고 비교할 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="named-attribute"></a>

## Named Attribute / 이름 있는 속성

**뜻:** 이름으로 다시 찾아 읽을 수 있는 [속성 자료](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#attribute).

**원리·용도:** 이름·자료형·[도메인](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#domain)을 맞춰야 한다. 이름만 같고 의미가 다르면 엉뚱한 결과가 나온다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="anonymous-attribute"></a>

## Anonymous Attribute / 익명 속성

**뜻:** 사용자가 문자열 이름을 정하지 않고 연결로 전달하는 속성.

**원리·용도:** 필요한 형상 흐름이 끊기면 자료를 평가할 수 없을 수 있다. 일반 [상수](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#constant)와 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="geometry-component"></a>

## Geometry Component / 형상 구성 요소

**뜻:** 형상 묶음 안의 [메시](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mesh)·[커브](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#curve)·점 무리·[인스턴스](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#instance) 같은 종류.

**원리·용도:** 같은 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node)도 지원하지 않는 종류에는 [적용](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#apply)되지 않을 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="selection-field"></a>

## Selection Field / 선택 필드

**뜻:** 요소마다 처리할지 말지를 계산하는 규칙.

**원리·용도:** Z가 0보다 큰 점만 움직이도록 제한할 수 있다. 화면에서 클릭해 고르는 [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)과 저장 방식이 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="boolean-value"></a>

## Boolean Value / 불리언 값

**뜻:** 참 또는 거짓 두 상태로 나타낸 값.

**원리·용도:** [선택](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection) 조건 계산에 쓴다. 입체를 합치고 빼는 [Boolean](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#boolean) [모디파이어](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier)와 뜻의 사용처가 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="simulation-zone"></a>

## Simulation Zone / 시뮬레이션 존

**뜻:** 이전 시간 단계의 결과를 다음 단계 계산에 사용하는 [노드](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#node) 구역.

**원리·용도:** 매 [프레임](06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#frame) 위치에 속도를 더하는 식의 상태 있는 계산을 만들 수 있다. 다시 재생할 때 저장 상태를 확인한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="repeat-zone"></a>

## Repeat Zone / 반복 존

**뜻:** 한 번 평가하는 동안 같은 처리를 정한 횟수 반복하는 구역.

**원리·용도:** 시간이 흐르는 [시뮬레이션](08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#simulation)과 달리 하나의 결과를 만들기 위한 반복이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="spreadsheet"></a>

## Spreadsheet / 스프레드시트 에디터

**원리·용도:** 화면 모양만으로 알기 어려운 [인덱스](07_%EC%A7%80%EC%98%A4%EB%A9%94%ED%8A%B8%EB%A6%AC%EB%85%B8%EB%93%9C.md#index)·위치·속성 값을 검사한다.
