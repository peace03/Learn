## Light / 라이트 / 광원

**뜻:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)에 빛을 공급하는 대상.

**원리·용도:** [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)을 그대로 둬도 위치·크기·세기를 바꾸면 보이는 결과가 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="point-light"></a>

## Point Light / 점광원

**뜻:** 한 점에서 여러 방향으로 퍼지는 빛.

**원리·용도:** 전구 같은 국소 조명의 근사에 쓴다. 실제 크기 설정은 [그림자](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shadow) 부드러움에 영향을 준다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="sun-light"></a>

## Sun Light / 태양광

**뜻:** 거의 평행한 방향으로 오는 먼 빛의 근사.

**원리·용도:** 위치보다 [회전](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation) 방향이 중요하다. 창밖 햇빛 같은 [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)에 쓴다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="spot-light"></a>

## Spot Light / 스포트라이트

**뜻:** 원뿔 범위로 제한된 빛.

**원리·용도:** 무대 조명·손전등에 쓴다. [각도](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#angle)와 가장자리 부드러움으로 범위를 정한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="area-light"></a>

## Area Light / 면광원

**뜻:** 면적을 가진 표면에서 나오는 빛의 근사.

**원리·용도:** 넓은 창·사진 조명처럼 부드러운 [그림자](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shadow)와 반사를 만든다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="world-shader"></a>

## World / 월드 셰이더

**뜻:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)을 둘러싼 환경의 배경·조명 설정.

**원리·용도:** 물체 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)과 별개다. 환경 이미지를 넣으면 여러 방향의 빛과 반사 정보로 쓰일 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="hdri"></a>

## HDRI

**뜻:** 넓은 밝기 범위를 저장한 환경 이미지.

**원리·용도:** 하늘과 밝은 태양 차이를 일반 그림보다 넓게 담아 조명에 쓴다. 모든 .[hdr](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#hdr) 파일이 좋은 조명을 보장하지는 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="shadow"></a>

## Shadow / 그림자

**뜻:** 빛이 다른 물체에 가려 덜 도달한 영역.

**원리·용도:** [광원](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#light)의 크기·거리·표면 위치에 따라 가장자리가 달라진다. [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material) 기본 색과 구별한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="camera"></a>

## Camera / 카메라

**뜻:** 최종 그림에 어떤 범위를 담을지 정하는 대상.

**원리·용도:** 작업 [뷰포트](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport) [시점](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)과 따로 움직일 수 있다. 활성 카메라가 최종 렌더를 결정한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="focal-length"></a>

## Focal Length / 초점 거리

**뜻:** 렌즈가 담는 범위와 관련된 길이 값.

**원리·용도:** 같은 센서에서 길수록 좁은 범위를 담는다. 원근감은 [카메라](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)와 피사체의 위치 관계에도 의존한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="fov"></a>

## Field of View / FOV / 화각

**뜻:** [카메라](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)가 담는 [각도](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#angle) 범위.

**원리·용도:** 넓으면 더 많은 주변을 담지만 가장자리 형태가 과장될 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="clipping"></a>

## Clipping / 클리핑

**뜻:** 정한 범위 바깥의 표시·계산을 잘라내는 것.

**원리·용도:** [카메라](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)·[뷰포트](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport)의 근거리/원거리 제한 때문에 물체가 잘릴 수 있다. [Mirror](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)의 Clipping은 중앙을 넘지 못하게 하는 별도 기능이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="dof"></a>

## Depth of Field / DOF / 피사계 심도

**뜻:** [초점 거리](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#focal-length) 주변에서 선명하게 보이는 깊이 범위.

**원리·용도:** 배경 흐림 연출에 쓴다. 작업 화면의 숨김이나 [해상도](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#resolution) 문제와 다르다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="render"></a>

## Render / 렌더링

**뜻:** [장면](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene) [데이터](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#data)에서 최종 이미지를 계산하는 과정.

**원리·용도:** 모양·[재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)·빛·[카메라](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#camera)가 입력이며 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel) 이미지가 결과다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="render-engine"></a>

## Render Engine / 렌더 엔진

**뜻:** 이미지를 계산하는 구현 방식.

**원리·용도:** [EEVEE](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#eevee), [Cycles](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#cycles), [Workbench](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#workbench)는 목표와 계산 방식이 다르므로 같은 설정처럼 보여도 결과가 다를 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="eevee"></a>

## EEVEE / 이브이

**뜻:** 빠른 화면 확인과 렌더를 위한 [Blender](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#blender) [렌더 엔진](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#render-engine).

**원리·용도:** 화면 중심 계산과 여러 근사를 사용한다. 버전에 따라 빛·반사 기능이 달라지므로 오래된 메뉴를 그대로 따르지 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="cycles"></a>

## Cycles / 사이클스

**뜻:** 광선의 경로를 [표본](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#sample)으로 [추적](09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#tracking)해 빛을 계산하는 [렌더 엔진](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#render-engine).

**원리·용도:** 복잡한 간접광 표현에 유용하다. 표본이 적으면 점처럼 보이는 [노이즈](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#noise)가 남을 수 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="workbench"></a>

## Workbench / 워크벤치

**뜻:** 모양을 확인하기 위한 간단한 표시 중심 [렌더 엔진](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#render-engine).

**원리·용도:** 정교한 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)·조명 결과를 [검증](10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#validation)하는 용도와 구분한다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="rasterization"></a>

## Rasterization / 래스터화

**뜻:** 투영한 면이 화면의 어느 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel)을 덮는지 구하는 과정.

**원리·용도:** [실시간](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#realtime) 그래픽의 주요 단계다. 모든 빛 경로를 직접 [추적](09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#tracking)한다는 뜻은 아니다.

## Ray Tracing / 레이 트레이싱

**뜻:** 광선을 따라 물체와 만나는 위치 등을 계산하는 방법.

**원리·용도:** 반사·[그림자](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shadow) 등을 구할 때 쓴다. 광선을 쓴다고 모든 조명이 자동으로 정확해지는 것은 아니다.

## Path Tracing / 패스 트레이싱

**뜻:** 빛이 여러 번 반사·통과하는 경로를 [표본](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#sample) 추출해 계산하는 방식.

**원리·용도:** 많은 경로의 평균으로 밝기를 추정한다. 표본 수와 [노이즈](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#noise) 사이에 관계가 있다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="sample"></a>

## Sample / 샘플 / 표본

**뜻:** 전체를 한 번에 계산하기 어려울 때 뽑아 조사하는 한 계산 값.

**원리·용도:** 렌더에서는 [픽셀](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#pixel)의 빛 경로를 여러 번 조사한다. 샘플 수가 많으면 시간이 늘지만 다른 모델 오류까지 고치지는 않는다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

## Real-time / 실시간

**원리·용도:** 빠른 결과를 위해 근사나 저장된 자료를 쓸 수 있다. 모든 설정에서 일정 속도를 보장하는 말은 아니다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="shading"></a>

## Shading / 셰이딩 / 음영 계산

**뜻:** 표면·빛·[시점](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view) 자료로 보이는 밝기와 색을 계산하는 작업.

**원리·용도:** [그림자](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shadow)만 뜻하지 않는다. [법선](03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#normal)이나 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)이 바뀌면 같은 표면에서도 결과가 달라진다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="reflection-light"></a>

## Light Reflection / 빛 반사

**뜻:** 들어온 빛이 물체 경계에서 돌아가는 현상.

**원리·용도:** 물체 [좌표](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate)를 뒤집는 [Mirror](02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#reflection)와 다르다. 거울 [재질](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)과 거울 [복제](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#duplicate)는 서로 별도 기능이다.

<a id="refraction"></a>

## Refraction / 굴절

**뜻:** 매질 경계에서 빛 진행 방향이 달라지는 현상.

**원리·용도:** 유리 너머 형태가 휘어 보이는 이유다. [IOR](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#ior)와 입사 방향이 관계된다.

## Absorption / 흡수

**뜻:** 빛이 물질에 들어가며 줄어드는 현상.

**원리·용도:** 두꺼운 유리나 연기에서 색과 밝기가 달라지는 데 관계된다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="scattering"></a>

## Scattering / 산란

**뜻:** 빛이 [입자](08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#particle)·물질과 만나 여러 방향으로 흩어지는 현상.

**원리·용도:** 안개가 빛줄기를 보이게 하거나 피부가 부드럽게 보이는 원리와 관계된다.

<a id="sample-rate"></a>

## Sample Rate / 샘플률

**뜻:** 1초 동안 소리 등의 연속 신호 값을 기록하는 횟수.

**원리·용도:** 48,000Hz는 초당 48,000번이다. 영상 [FPS](06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#fps)와 서로 다른 시간 [표본](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#sample) 기준이다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="hz"></a>

## Hz / 헤르츠

**뜻:** 1초에 반복되는 횟수를 나타내는 단위.

**원리·용도:** 소리 주파수·[표본](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#sample)률 등에 쓰인다. 수치가 쓰인 대상이 무엇인지 함께 읽는다.

<a id="bit-depth"></a>

## Bit Depth / 비트 깊이

**뜻:** 값 하나를 표현하는 데 사용하는 [비트](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#bit) 수.

**원리·용도:** 단계 수와 [정밀도](10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#precision)·메모리에 영향을 준다. 이미지의 가로세로 [해상도](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#resolution)와 별개다.

[분야 목차로](#field-index) · [전체 용어 색인](README.md)

<a id="bit"></a>

## Bit / 비트

**뜻:** 0 또는 1 중 하나를 담는 정보 단위.

**원리·용도:** 여러 비트를 묶어 숫자·문자·색을 표현한다. [비트레이트](09_2D%ED%95%A9%EC%84%B1%EA%B3%BC%EC%98%81%EC%83%81.md#bitrate)는 시간당 이 자료의 양이다.

<a id="compression"></a>

## Compression / 압축

**뜻:** 자료를 더 적은 저장 공간으로 표현하는 방법.

**원리·용도:** 손실 압축은 일부 정보를 버리고, 무손실은 원래 값을 복원할 수 있다. 실제 메모리 사용량은 파일 크기와 다를 수 있다.

<a id="noise"></a>

## Noise / 노이즈

**뜻:** [문맥](01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#context)에 따라 불규칙한 무늬 또는 계산 [표본](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#sample) 부족의 얼룩.

**원리·용도:** [절차적](04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#procedural) 노이즈는 의도한 무늬, 렌더 노이즈는 보통 줄이고 싶은 불안정한 밝기 차이다.

<a id="denoise"></a>

## Denoise / 디노이즈

**뜻:** 계산 [노이즈](05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#noise)를 주변 정보로 추정해 줄이는 과정.

<a id="linear"></a>

## Scene Linear / 선형 색

**뜻:** 값을 두 배로 했을 때 표현하는 빛의 양도 두 배가 되도록 한 계산 기준.

**원리·용도:** 빛을 더하고 섞을 때 사용한다. 화면에 저장된 일반 사진 숫자를 그대로 더하는 것과 다르다.
