## 이번 부츠에서 먼저 알아둘 사실

**현재 모델은 X 방향으로 좌우가 나뉘고 Z가 위쪽입니다. 반대 발용 부츠는 X=0인 세로 [평면](90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#plane)에 거울 반전합니다.** Z 반전은 위아래를 뒤집으며, Z축 180도 [회전](90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)은 발끝 방향도 돌립니다.

현재 부츠 `Boots1-1`에는 뼈 연결이 없고, [장면](90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#scene)의 [뼈대](90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#armature)는 치마용입니다. 실습의 현재 완료 지점은 **반대 발에 맞춘 별도 부츠 [오브젝트](90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)를 저장하는 것**입니다. 발 움직임에 따라 휘게 만드는 연결은 실제 다리·발 뼈가 마련되어야 합니다. [연결 방식과 현재 조건](10_목적별/001_반대발_부츠/06_배치와_뼈연결.md)을 반드시 구분해서 읽습니다.

자료 작성 과정에서는 열려 있는 모델을 읽기만 했습니다. 복제·반전·저장·리깅을 실제 모델에 실행하지 않았습니다. [근거와 검증 범위](99_관리/공식근거와_검증기록.md)에 세부 내용을 적었습니다.
