# 01. 화면과 조작부터 익히기

목표는 단축키 암기보다 **어디에서, 무엇을 [선택](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#selection)하고, 어떤 상태로 실행하는지**를 아는 것입니다. 이 문서의 ‘클릭’은 왼쪽 버튼 한 번, ‘드래그’는 누른 채 이동한 뒤 놓기입니다. `Shift+클릭`은 Shift를 누른 채 클릭합니다. `G → X → 0.01 → Enter`는 네 입력을 순서대로 합니다.

## 화면은 여러 작업 창으로 나뉜다

| 화면 이름 | 어디를 보고 무엇을 하나 |
|---|---|
| [3D Viewport](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#viewport) | 가장 큰 입체 작업 영역. 모형을 보고 선택한다 |
| [Outliner](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#outliner) | 보통 오른쪽 위의 이름 목록. `Boots1-1`처럼 정확한 대상을 찾는다 |
| [Properties](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#properties) | 보통 오른쪽 아래의 아이콘 탭 모음. [재질](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#material)·[모디파이어](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#modifier) 등을 설정한다 |
| [Timeline](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#timeline) | 보통 아래쪽의 시간 눈금. 현재 [프레임](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/06_%EB%A6%AC%EA%B9%85%EA%B3%BC%EC%95%A0%EB%8B%88%EB%A9%94%EC%9D%B4%EC%85%98.md#frame)과 재생을 조절한다 |
| [Sidebar](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#sidebar) | 뷰포트 안에서 N으로 여는 옆 설정. [Item](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#item)에서 위치·[회전](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#rotation)·크기를 읽는다 |

작업 탭인 [Layout](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#layout)·[Modeling](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#modeling)·[Shading](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/05_%EC%A1%B0%EB%AA%85%EB%A0%8C%EB%8D%94%EC%83%89.md#shading)은 창 배치입니다. 탭을 바꾸었다고 새 파일이 생기지 않습니다. 창이 없으면 해당 구역 [모서리](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/03_%EB%A9%94%EC%8B%9C%EC%99%80%EB%AA%A8%EB%8D%B8%EB%A7%81.md#edge)의 **[Editor](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#editor) Type** 아이콘을 클릭해 종류를 바꿀 수 있습니다. 익숙하지 않다면 위쪽 Layout 탭에서 시작합니다.

단축키는 **마우스가 올라간 창**에서 작동합니다. 부츠를 이동할 때는 마우스를 3D Viewport 안으로 옮긴 뒤 키를 누릅니다. N으로 연 Sidebar와 별도 Properties 창을 구분합니다.

## 선택과 모드는 먼저 확인한다

1. Outliner에서 대상 이름을 클릭합니다. 이름이 많으면 위쪽 검색 칸에 `Boots1-1`을 입력합니다.
2. 3D Viewport 왼쪽 위 [모드](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mode) 메뉴가 **[Object Mode](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object-mode)**인지 확인합니다. 아니면 메뉴를 클릭해 Object Mode를 고릅니다.
3. 선택 윤곽과 목록 강조가 원하는 물체 하나에만 있는지 확인합니다.
4. N을 눌러 Sidebar를 열고 **Item → [Transform](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#transform)**을 펼칩니다. 숫자는 선택된 [활성 오브젝트](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#active)의 값입니다.

Object Mode는 물체 전체를, [Edit Mode](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#edit-mode)는 내부 점·선·면을, [Pose Mode](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#pose-mode)는 뼈 자세를 바꿉니다. **같은 키라도 모드가 다르면 다른 자료를 바꿉니다.** Tab은 주로 [Object](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#object)/Edit 전환에 쓰지만 모든 종류에서 같은 모드가 열리는 것은 아닙니다.

## 물체 자체를 바꾸는 조작

| 목적 | 입력 | 끝내기 |
|---|---|---|
| 이동 | G → X/Y/Z → 수 | Enter 또는 왼쪽 클릭 |
| 회전 | R → X/Y/Z → [각도](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#angle) | Enter |
| 크기 변경 | S → 필요하면 X/Y/Z → 비율 | Enter |
| 지금 진행 중인 변환 취소 | Esc 또는 오른쪽 클릭 | 해당 변환만 취소 |
| 완료한 직전 작업 되돌리기 | Ctrl+Z | 한 단계 [실행 취소](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#undo) |

키보드 명령 대신 왼쪽 [Toolbar](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#toolbar)의 Move·Rotate·[Scale](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#scale)을 선택해 축 손잡이를 드래그할 수 있습니다. 정확한 수가 필요하면 Sidebar의 숫자를 더블 클릭해 입력합니다. 단위·[좌표](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#coordinate) 방향·[피벗](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#pivot)을 확인한 뒤 입력해야 합니다.

## 저장은 두 종류의 자료를 확인한다

File → [Save As](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#save-as)에서 **새 이름**을 입력하고 Save As를 누르면 지금 메모리에 있는 상태를 새 파일로 저장합니다. 창 제목이나 [File Browser](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#file-browser) 경로로 새 파일인지 확인합니다. 이미 존재하는 파일이면 덮어쓰기 대상을 다시 읽습니다.

[blend 파일](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#blend)은 외부 이미지·[캐시](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/08_%EB%AC%BC%EB%A6%AC%EC%99%80%EC%8B%9C%EB%AE%AC%EB%A0%88%EC%9D%B4%EC%85%98.md#cache)를 참조할 수 있습니다. 파일 하나를 저장했다고 모두 들어간 것은 아닙니다. [텍스처](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/04_UV%EC%99%80%EC%9E%AC%EC%A7%88.md#texture)를 칠했다면 이미지의 저장 상태도 별도로 확인합니다. 이번 부츠 실습은 기존 파일 옆에 새 blend를 저장해 [상대 경로](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/10_%ED%8C%8C%EC%9D%BC%EC%9E%90%EB%8F%99%ED%99%94%EC%84%B1%EB%8A%A5.md#relative-path)가 유지되기 쉽게 합니다.
