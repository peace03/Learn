# 02. Blender 전체 개념 지도

컴퓨터의 입체 물체는 작은 실물 모형이 아닙니다. **숫자로 기록한 모양, 표면의 성질, 빛, [시점](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/02_%EC%A2%8C%ED%91%9C%EC%99%80%EB%B3%80%ED%99%98.md#view)**을 계산해 화면의 색칸으로 보여 줍니다. 물체가 검게 보일 때 모양이 사라진 것인지, 조명이 없는 것인지, 표시 [모드](../90_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84/01_%ED%99%94%EB%A9%B4%EA%B3%BC%EB%8D%B0%EC%9D%B4%ED%84%B0.md#mode)가 다른지 나누어 찾는 이유입니다.

```text
점의 위치 + 연결 관계 → 모양
모양 + UV + 재질       → 표면의 색과 빛 반응
표면 + 조명 + 카메라   → 렌더 이미지
뼈/키프레임/물리       → 시간에 따른 장면 변화
여러 이미지 + 소리     → 합성·편집한 영상
```
